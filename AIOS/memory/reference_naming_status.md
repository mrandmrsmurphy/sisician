As of 2026-09-18, only the English/historical working names existed: **Siscia** (ancient/Latin name), **Sisak** (modern town), **Sisician** (English name for the language/culture, confirmed 2026-09-18).

**Decided 2026-09-25: the founder's personal name.** **Vitalis Madius de Corinio** (vernacular *Vitale Madi de Karin*) — see [[../../Culture/Founding Myth and Naming|Culture/Founding Myth and Naming]] § The Founder for the full derivation. This one didn't need to wait on Phase 3: it's a real Dalmatian/Latin personal name and patronymic (Vitalis, Madius) plus a real, verified place-name (Corinio/Karin, checked against the historical record after an initial proposal — Vrana — turned out to be anachronistic, a monastic property in this period rather than a lay lord's holding), not something Sisician's own historical phonology needs to generate.

**Decided 2026-09-25: the native endonym.** **сисачки (sisački)** — see [[../../Words/сисачки|Words/сисачки]] for the full derivation. Unlike the founder's own name, this one genuinely did need Phase 3: it's built by applying already-decided Sisician sound changes (Fall of the Jers, first palatalization, the long-form adjective *-и* ending) to the real toponymic chain Segestica→Siscia→Siscium→Сисак, plus the real Common Slavic language-adjective suffix *\*-ьskъ*. The first name in the vault actually generated *from* the phonology rather than cited from real history or from Dalmatian material.

**Still open by design**, waiting on the same precondition сисачки just satisfied: name of the people, name of the polity, name of the dynasty, and the title of the lord.

**Why the remaining names stay undecided:** The user's explicit principle is "do not invent a name until we know the sound changes" (see [[../../Culture/Founding Myth and Naming|Culture/Founding Myth and Naming]] § Naming — Open Questions). Unlike the founder's own name — a real historical citation, not a Sisician coinage — these names (сисачки included) are meant to be generated *from* the historical phonology, not invented arbitrarily ahead of it — inventing them early would be exactly the "design a feature first and retrofit an etymology" mistake the whole project is built to avoid. сисачки shows this is now a live, working process, not just a stated intention.

**How to apply:** Do not propose or invent the dynasty/polity/people names or the lord's title until they get the same actual derivation pass сисачки just did (the sound-change sequence itself, [[../../Etymology/Sisician Sound Changes|Etymology/Sisician Sound Changes]], has been done since 2026-09-20 — it's the *derivation*, not the phonology, that's still owed for these). If the user asks for one of these before that derivation happens, say so rather than generating one anyway. Vitalis's descendants should acquire Slavic names generation by generation (Vitalis → mixed → Slavic-Christian → fully local) — that naming shift is itself part of the design, and unlike the names above, individual descendant names can be real Slavic personal names (no phonology-derivation precondition), the same way Vitalis's own name was.
