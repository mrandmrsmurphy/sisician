As of 2026-09-18, only the English/historical working names exist: **Siscia** (ancient/Latin name), **Sisak** (modern town), **Sisician** (English name for the language/culture, confirmed 2026-09-18). Everything else is open by design: the native endonym, name of the people, name of the polity, name of the dynasty, the founder's personal name, his title, and the name of the language as its own speakers would say it (the endonym).

**Why:** The user's explicit principle is "do not invent the endonym until we know the sound changes" (see [[../../Culture/Founding Myth and Naming|Culture/Founding Myth and Naming]] § Naming — Open Questions). These names are meant to be generated *from* the historical phonology once it exists (Phase 2–3 of [[reference_construction_workflow]]), not invented arbitrarily ahead of it — inventing them early would be exactly the "design a feature first and retrofit an etymology" mistake the whole project is built to avoid.

**How to apply:** Do not propose or invent the endonym, personal names, titles, or the dynasty/polity/people names until the sound-change sequence (Phase 3) exists. If the user asks for a name before then, say so rather than generating one anyway. The founder's own name should be historically Dalmatian/Latin, with descendants acquiring Slavic names generation by generation (Founder → mixed → Slavic-Christian → fully local) — that naming shift is itself part of the design, once real names exist.
