# Verb Paradigm (Sketch)

A first sketch, not a finished system — one example verb per present-tense conjugation class, plus one verb's fuller picture across present and past. See [[Verbal Categories]], [[Verbal Agreement]], [[Biti (To Be)]], and [[Past Tense Fusion and Evidentiality]] for the pieces this assembles. See [[../Sisician|Sisician]] for the hub page.

## Three Conjugation Classes — Echoing the Noun Declension Classes

**Confirmed: Sisician keeps real Croatian's three present-tense conjugation classes**, traditionally named by their stem vowel — **-a-, -e-, -i-** — the same naming logic as [[Declension Classes]]'s a/e/i noun classes, just applied to verbs instead of nouns. No reason to invent anything different here any more than elsewhere.

### A-type: гледати "to watch/look"

| | Singular | Plural |
|---|---|---|
| 1st | ГЛЕ́дам | ГЛЕ́дамо |
| 2nd | ГЛЕ́даш | ГЛЕ́дате |
| 3rd | ГЛЕ́да | ГЛЕ́дају |

### E-type: нести "to carry"

| | Singular | Plural |
|---|---|---|
| 1st | НЕ́сем | НЕ́семо |
| 2nd | НЕ́сеш | НЕ́сете |
| 3rd | НЕ́се | НЕ́су |

**Confirms something already built**: this -ем/-еш/-е/-емо/-ете/-у pattern is exactly [[Biti (To Be)]]'s будем/будеш/буде/будемо/будете/буду — будем was already an e-type verb, just biti's own special perfective-present paradigm rather than an ordinary lexical verb. Good internal consistency, not a coincidence to explain away.

### I-type: радити "to do/work"

| | Singular | Plural |
|---|---|---|
| 1st | РА́дим | РА́димо |
| 2nd | РА́диш | РА́дите |
| 3rd | РА́ди | РА́де |

All three follow root-anchored stress ([[../Phonology/Modern Inventory|Modern Inventory]] § Prosody) — every form above stresses the lexical root (гле-, не-, ра-), never the conjugation ending.

## радити's Fuller Picture: Present + the Full Past-Tense Person Paradigm

[[Past Tense Fusion and Evidentiality]] only worked out радити's 3rd-person past forms in detail. Here's the complete person paradigm, showing how the pieces fit together — 3rd person gets the full three-way contrast, 1st/2nd person stay conservative always (per that page's confirmed scope):

| | Singular | Plural |
|---|---|---|
| 1st (conservative only) | сам радио / сам радила | смо радили / смо радиле |
| 2nd (conservative only) | си радио / си радила | сте радили / сте радиле |
| 3rd, conservative | је радио / је радила | су радили / су радиле |
| 3rd, fused (witnessed) | ЈРА̀дио / ЈРА̀дила | СРА̀дили / СРА̀диле |
| 3rd, dropped (hearsay) | радио / радила | радили / радиле |

Note pro-drop ([[Verbal Agreement]]) means the subject pronouns (јаз, ти, он/она, ми, ви, они/оне) shown here are optional in all of the above — included for clarity, not because they're required.

## Explicitly Not Yet Built

This is a sketch, per your own framing — the following are real, needed pieces that this page doesn't attempt:

- **Imperative** forms for any class ([[Verbal Categories]] confirmed it's a must-have category; no endings sketched yet).
- **Aorist/imperfect** endings (category and timeline decided in [[Verbal Categories]], forms not built).
- **Future I/II, pluperfect, conditional** — categories are settled ([[Verbal Categories]]), but none of these compound forms have been assembled for a real verb yet (only будем itself, biti's own contribution, exists in finished form).
- **The бих-series conditional auxiliary** itself (flagged unbuilt since [[Biti (To Be)]]).
- **Which verbs belong to which class** — three example verbs were picked to illustrate the classes, not to establish a rule for predicting a new verb's class from its shape. Real Croatian's class assignment has its own patterns (largely tied to infinitive ending and historical thematic vowel) that haven't been worked out for Sisician specifically.
- **Aspect pairs** (perfective/imperfective partners for a given verb, e.g. a real Slavic verb typically comes in a matched pair) — confirmed as inherited bedrock in [[Verbal Categories]], but no actual aspectual pairs have been built for any Sisician verb yet.
