# Demonstrative Pronouns

Decided 2026-09-23. See [[Personal Pronouns]] for the sibling paradigm this parallels structurally (and shares its *jь etymological material with — see [[../Words/он|Words/он]] and [[Adjective Agreement]]), [[Nominal Morphology]] for the case/gender system this reflects, and [[../Sisician|Sisician]] for the hub page.

## The System: Two-Way, Not Three-Way

Real Serbo-Croatian has a three-way deictic contrast, all three built on the same historical mechanism ([[Adjective Agreement]]'s "long form = short form + *jь", applied here to bare demonstrative roots instead of adjectives):

- **Proximal** (near speaker) — **\*ovъ + \*jь → овај** "this"
- **Medial** (near addressee) — **\*tъ + \*jь → тај** "that"
- **Distal** (away from both) — **\*onъ + \*jь → онај** "that (over there)"

**Sisician builds only the first two.** The distal slot's root, *\*onъ*, is the same root already grammaticalized into [[../Words/он|он]] "he/it" — real Serbo-Croatian keeps *on* "he" and *onaj* "that (yonder)" as two separate, non-colliding words built from the same root (the suffix is exactly what keeps them apart), so there's no structural reason Sisician couldn't build онај too. It just hasn't been asked for — [[../Etymology/Swadesh List|Etymology/Swadesh List]] only calls for one English "this" and one English "that" (items 7–8), and тај already covers "that" without needing the distal slot. Онај is a coherent, available extension if a future need for a third distance grade ever comes up — not a blocked or rejected slot.

## The Two Paradigms

Both follow the identical suffixation mechanism, so they're given together. Only living forms shown — no dead cases (locative/vocative), per standing convention.

**Neuter merger applied**, per [[Nominal Morphology]] — no separate neuter row, same mechanism already used everywhere else in this project ([[../Words/он|он]], [[../Words/оне|оне]], [[../Grammar/Adjective Agreement|Adjective Agreement]]'s нув): an old-neuter-**singular** referent takes the masculine singular form; an old-neuter-**plural** referent takes the feminine plural form.

**Real, inherited syncretisms, not artifacts** — the same "expect real Slavic homophony, don't engineer around it" stance already applied throughout this vault (каза's nom.sg.=gen.pl., [[../Grammar/Personal Pronouns|Personal Pronouns]]'s dative=instrumental plural, etc.):

- **Genitive singular feminine = nominative/accusative plural (both genders)**: те serves та's genitive singular *and* тај/та's own plural nominative(f.)/accusative(both genders) — three grammatically distinct cells, one form, confirmed directly against the real Serbo-Croatian *taj* declension table (genitive fem. *tȇ*, plural accusative *tȇ*, identical to plural fem. nominative *tȇ*). Ове is the exact structural twin for the proximal set.
- **Masculine singular instrumental = plural dative = plural instrumental (both genders)**: тим fills three cells at once, confirmed the same way (real *tȋm* masc.sg.instr. = real plural *tȉm* dat./instr.). Овим is the exact structural twin.
- **Accusative masculine singular depends on animacy**, exactly mirroring [[../Words/дом|дом]]'s and [[../Grammar/Adjective Agreement|Adjective Agreement]]'s нув's own established animacy rule: inanimate reuses the nominative (тај/овај), animate reuses the genitive (тога/овога).

## A Real Inherited Homophony: ти = "those" AND "thou"

**Not a design flaw, not a coincidence engineered for effect — a genuine convergence of two unrelated Proto-Slavic roots landing on the same surface form.** The demonstrative masculine plural continues Proto-Slavic *\*ti* (bare, no suffixation needed — see [[../Words/ти|Words/ти]] § Etymology, second sense, for why only the masculine *singular* needed the *jь reinforcement). The personal pronoun continues an entirely separate root, *\*ty* "thou" ([[../Words/ти|Words/ти]]'s original sense), which independently arrives at /ti/ via the same general South Slavic *y→i* merger already documented on that page. Two different Proto-Slavic words, two different sound changes, one modern surface form — resolved by syntactic context exactly the way [[../Grammar/Personal Pronouns|Personal Pronouns]] already accepts for [[../Words/ми|ми]] (1pl "we" / 1sg dative clitic "to me") and [[../Words/ти|ти]] itself (nominative "thou" / dative clitic "to you"). This is the *third* instance of this exact kind of accepted collision in the vault, not a new category of problem.

## Etymology — Shared Mechanism, Two Root Sets

**The masculine singular is the one cell in each paradigm that needed reinforcement.** Per [[Adjective Agreement]]'s own already-established derivation (confirmed there via Wiktionary's *novъ appendix), a bare monosyllabic jer-final root like *\*tъ* or *\*ovъ* doesn't survive as an independent word once [[../Etymology/Fall of the Jers|Fall of the Jers]] applies to it in isolation — the jer is word-final, hence weak, hence it simply vanishes, leaving an unpronounceable bare consonant (*t-*) or an unremarkable short form. Suffixing the anaphoric pronoun *\*jь* fixes this: now the root's jer is no longer word-final (the suffix's own jer, *ь*, is), so Havlík's Law's alternating count applies properly — **rightmost jer (suffix *ь*) is weak, drops; the root's own jer, now non-final, is strong, and vocalizes to *a*** (the same South Slavic ъ/ь→a outcome already established on [[../Etymology/Fall of the Jers|Fall of the Jers]]). The suffix's onset consonant *j* survives, since it's a consonant, not the vowel that dropped. Worked through directly:

- ***tъ* + *jь* → t-ъ(strong→a)-j-ь(weak→∅) → тај*** — matches real Serbo-Croatian *tȃj* exactly (confirmed via Wiktionary: "Inherited from Proto-Slavic *tъ + *jь").
- ***ovъ* + *jь* → o-v-ъ(strong→a)-j-ь(weak→∅) → овај*** — matches real Serbo-Croatian *òvāj* exactly (confirmed via Wiktionary: "*ovъ-jь*, combining the original demonstrative with an additional morphological element").

**The feminine singular and both plurals never needed this fix**, because their Proto-Slavic forms were already full-vowel-final, not bare jers, so they're inherited directly with no suffixation step at all — confirmed against Wiktionary's *tъ reconstruction table (full nominative paradigm: masc. *\*tъ*, fem. *\*ta*, plural masc. *\*ti*, fem. *\*ty*):

- **та** ← *\*ta* directly (already a full vowel in Proto-Slavic).
- **ти** (masc.pl. "those") ← *\*ti* directly.
- **те** ← *\*ty*, via the same old pronominal/adjectival plural *-y→-e* (yat) merger already established for [[../Words/оне|оне]] (*\*ony→оне) and [[Adjective Agreement]]'s нуве — not a fresh sound change, the identical mechanism showing up a third time in the same morphological slot.
- **ова, ови, ове** — same pattern, one root over: *\*ova, \*ovi, \*ovy→ове* (the last via the identical -y→-e merger). Confirmed against a fresh Wiktionary fetch of Serbo-Croatian *ovaj*'s own declension table (nom.: sg. *òvāj/òvā/òvō*, pl. *òvī/òvē/òvā*).

**This is not a new sound change or a new mechanism** — every step above (Havlík's Law, the South Slavic a-outcome, the *jь* suffixation already behind он's oblique stem and нув's long form, the pronominal -y→-e merger already behind оне) was already on the books before this pair was built. Тај/овај are simply the first place three previously-separate established facts combine into one derivation.

## Etymology — The Oblique Paradigm

**A real structural reason the *jь-suffix is masculine-nominative-singular-only.** Every oblique case ending (*-ogo, -omu, -ěmь*, etc.) is already vowel-initial, so a root jer immediately followed by one was never word-final to begin with — Havlík's Law never made it weak, so it never needed *jь-reinforcement the way the bare nominative did. This is why тога/тому/тим attach oblique endings directly to the bare root **т-**, not to the nominative-specific compound тај — confirmed directly against Wiktionary's *tъ declension table (masc.sg. genitive *\*togo*, dative *\*tomu*, instrumental *\*těmь*; plural genitive *\*těxъ*, dative *\*těmъ*, instrumental *\*těmi*) and the real Serbo-Croatian *taj*/*ovaj* declension tables (masc.sg. gen. *tȍgā*, dat. *tȍmu*, instr. *tȋm*; plural gen. *tȋh*, dat./instr. *tȉm*).

**These are not fresh endings — they're the identical -ога/-ому/-им/-их ending family already established on [[../Grammar/Adjective Agreement|Adjective Agreement]]'s нув (definite genitive нувога, dative нувому, instrumental нувим, genitive plural нувих) and on [[../Words/он|он]]'s own oblique stem (њега, њему, њим, њих) — the same historical *jь-pronoun declension underlying all three paradigms, per [[Adjective Agreement]]'s own already-established point that the long-form adjective ending literally *is* this pronoun's declension fused onto a nominal stem.** Тога/тому/тим/тих and овога/овому/овим/ових are simply this same, already-cited ending set applied to a fourth (and fifth) lexeme, not new material.

**Feminine singular oblique (те/тој/ту/том, ове/овој/ову/овом)** matches [[../Words/он|он]]'s own feminine oblique stem (ње/њој/њу/њом) and [[Adjective Agreement]]'s нув(е)/нувој/нуву/нувом ending-for-ending — the same already-flagged "pronominal genitive-singular-feminine ending family" ([[../Words/ње|ње]]'s own etymology note) showing up a third time. Confirmed against the real Serbo-Croatian tables: fem. genitive *tȇ*/*òvē*, dative *tȏj*/*òvōj*, accusative *tȗ*/*òvū*, instrumental *tȏm*/*òvōm*.

**The *-im (not *-em) instrumental/plural vowel is inherited real-Croatian texture, not independently derived** — Proto-Slavic's *\*těmь* would regularly denote an *e*-vowel outcome under this vault's own Ekavian yat convention (matching Sisician's established least-surprising reflex, e.g. [[../Words/лето\|lěto]]-type forms), but real Serbo-Croatian shows *-im* here, the same already-adopted analogical ending as [[../Words/он|он]]'s њим and [[Adjective Agreement]]'s нувим. Adopted directly rather than forced through a fake derivation, the same honesty standard already applied to [[../Words/нама|нама]]'s and [[../Words/тебе|тебе]]'s own unexplained vowels — flagged, not smoothed over.
