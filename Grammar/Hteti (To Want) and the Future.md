# Hteti (To Want) and the Future

Built 2026-09-25, filling in [[Verbal Categories]]'s Future I row — "че-clitic + infinitive **or** че-clitic + да + present" had been named since 2026-09-19 but never given an actual paradigm. Copied directly from real BCS's own **htjeti/hteti** system, the second major suppletive-feeling auxiliary verb after [[Biti (To Be)]], and structurally its closest parallel: a long/stressed lexical form, a short/clitic auxiliary form, and a fused negative — the same three-way split, on a different verb. See [[../Sisician|Sisician]] for the hub page.

## Etymology: Common Slavic \*xъtěti — a Real Root-Ablaut Verb, Not a Regularized One

**Confirmed via search this session.** Real *htjeti/hteti* continues Common Slavic **\*xъtěti** "to want," cognate with Russian **хотеть** and Ukrainian **хотіти**. Two genuinely different things happen to this one root depending on which form you're looking at, and Sisician inherits both rather than smoothing them into one shape:

- **The infinitive** continues the root with its yer (**хъ-**) and yat (**-tě-**) intact: \*xъtěti → **хтети**. The yer is weak (it's the only yer in the word, so Havlík's Law marks it weak by default) and drops via ordinary [[../Etymology/Fall of the Jers|Fall of the Jers]] — no vowel survives between х and т, matching real *htjeti*'s own हт- cluster exactly. The yat resolves via [[../Sources/Late Common Slavic|Late Common Slavic]]'s already-decided Ekavian reflex (ě→e), giving real Serbian *hteti*'s own vowel, not Croatian Ijekavian *htjeti*'s je/ije. **хт-** as a word-initial obstruent+obstruent onset is already independently attested as legal ([[../Phonology/Phonotactics|Phonotactics]], cf. кто), so no phonotactic repair is needed either.
- **The present tense is built on a different grade of the same root** — real Common Slavic \*xotjǫ ("I want"), with a plain **o** (not the infinitive's yer) plus the old thematic yod suffix *-j-*. This isn't a separate verb or an invented irregularity — it's a real, inherited ablaut alternation (the same broad phenomenon behind English *sing/sang/sung*-type vowel grades, just older and Slavic-specific), and real BCS keeps it too (*htjeti* the infinitive vs. *hoću* the present don't share a visible stem). Sisician keeps it rather than regularizing it away, the same "don't simplify what the source languages didn't" principle already applied to [[Biti (To Be)|биti]]'s own four-paradigm system.

The thematic *-j-* jotates the root-final /t/ the same way it does everywhere else in this vault (свеча, the -če deverbal-noun allomorph, etc.): **хот+ј → хоч-**, giving the present stem. Sisician's already-decided ć→č merger means this lands on **ч**, not real Croatian's **ć** — the same merger already applied throughout, not a fresh decision for this word.

## Long/Stressed Present — the Ordinary Lexical Verb "To Want"

Root-anchored stress on **хо-**, matching real BCS's own accent placement (*hòću*):

| | Singular | Plural |
|---|---|---|
| 1st | хо́чу | хо́чемо |
| 2nd | хо́чеш | хо́чете |
| 3rd | хо́че | хо́че |

**3rd plural = 3rd singular, inherited as-is, not regularized.** Real BCS's *hoće* covers both cells too — an old real syncretism (the expected thematic 3pl \*-ǫtъ didn't survive independently here), not a Sisician-specific leveling. Also note the irregular 1st singular: **хочу**, not †хочем — real BCS's *hoću* is the same way, an old athematic-looking 1sg ending that never regularized to match будем/несем's ordinary -ем pattern.

## Short/Clitic Present — the Future Auxiliary

Unstressed, proclitic, formed by dropping the long form's **хо-** — exactly the same relationship [[Biti (To Be)|сам]] has to **јесам**:

| | Singular | Plural |
|---|---|---|
| 1st | чу | чемо |
| 2nd | чеш | чете |
| 3rd | че | че |

**This is Future I.** [[Verbal Categories]] already named the construction; this supplies the missing paradigm. Per [[Infinitive Loss and Da-Complementation]]'s own timeline, the verbal complement changes shape over time:

| Stage | Construction | Example ("the sun will shine") |
|---|---|---|
| Old/Middle Sisician | че + infinitive | **сунце че сијати** |
| Modern Sisician | че + да + present | **сунце че да сија** |

Real BCS itself still shows both patterns living side by side today (the infinitive-based *ću vidjeti* skewing more formal/Croatian-standard, the да-based *ću da vidim* more colloquial/Serbian) rather than one having fully replaced the other even in the modern language — a real, live example of exactly the kind of centuries-long gradual coexistence [[Infinitive Loss and Da-Complementation]] already describes in the abstract.

**Slots into [[Clitic Ordering]]'s existing template with no new decision needed.** That page's AUX slot ("li — **AUX** (except је) — DAT — ACC/GEN — SE — је") was already stated generically, not restricted to биti's own clitics specifically — real Browne's ordering puts *any* weak verbal auxiliary clitic there, and че is exactly that. Reusing [[Clitic Ordering]]'s own [[../Words/респонџати|респонџати]] example: **Ја чу му респонџати** ("I will answer him," old/middle-period infinitive-based) stacks че before the dative clitic му exactly where биti's own сам/си/etc. already sit, confirming the template rather than requiring a fresh rule.

## Negative — Fused, Not Periphrastic, the Same Small Closed Class as Biti

**Real BCS glues negation directly onto only a small handful of verbs — *biti*, *htjeti*, and *imati* ("to have") are the classic three — rather than writing *ne* as a separate word the way it does for every ordinary verb.** [[Negation]] already established this for биti (не+јесам→нисам, an irregular fusion with internal vowel change); hteti's own fusion is much simpler — real *ne*+*ću*=*neću* is a plain, regular concatenation, no internal change at all, and Sisician's не+чу follows the identical straightforward path:

| | Singular | Plural |
|---|---|---|
| 1st | не́чу | не́чемо |
| 2nd | не́чеш | не́чете |
| 3rd | не́че | не́че |

Stress on **не-**, matching [[Biti (To Be)|нисам]]'s own precedent (**НИ́сам**-style, root-anchored on the negator itself). This is also the **negative future**: real BCS *neću vidjeti/da vidim* = "I will not see," the same auxiliary simply negated rather than a separate negative-future construction. Modern-period да-based example: **сунце нече да сија** ("the sun will not shine").
