# Negation

Decided 2026-09-23. See [[../Sisician|Sisician]] for the hub page.

## Two Words, One Real Sisician-Specific Split

**Real Croatian and Slovene both just use *ne* for everything** — verbal negation, the standalone "no" reply, negative predicate use, all one word. Sisician's split into [[../Words/не|не]] (verbal/adverbial negation) and [[../Words/нон|нон]] (adjective/interjection negation) is **not inherited from either source language — it's a genuine Sisician-specific innovation**, the same honesty category as [[Past Tense Fusion and Evidentiality]]'s own "first genuinely novel" claim, just a later instance of one.

**Why it's plausible anyway:** interjections and discourse particles are cross-linguistically *more* prone to prestige borrowing than almost any other word class — more so even than the core numerals [[../Words/ној|ној]] displaced (see [[../Grammar/Numerals|Grammar/Numerals]]). A standalone, emphatic "no!" or a dismissive negative-adjective use is exactly the kind of expressive, socially-marked slot where a Dalmatian-prestige alternative would plausibly take root even while the unmarked, grammatically-obligatory verbal negator stayed native.

## не — Verbal/Adverbial Negation

**Proto-Slavic \*ne → не directly.** Trivial, no Croatian/Slovene fork — both already show *ne* unmodified, and Sisician needs no adaptation at all. Already present, unremarked, inside [[../Grammar/Biti (To Be)|Biti (To Be)]]'s own fused negative present **нисам** (не + јесам → нисам, a real Slavic negation-fusion pattern) — that page never spelled out the fusion's own first half; this page is where it's finally named.

## нон — Adjective/Interjection Negation

**Latin NON → нон, with a genuinely interesting escape from Dalmatian's own diphthongization rule.** Classical Latin *nōn* has a long stressed ō (from a real, well-documented contraction of *ne oinom* "not one thing") — which would ordinarily trigger [[../Sources/Dalmatian|Dalmatian]]'s established stressed-ē/ō diphthongization (closed syllable, since NON ends in -n, would give *ō→uo→wa*, i.e. *nwan* — the same mechanism already responsible for [[../Etymology/Sisician Sound Changes|Sisician Sound Changes]]'s мварт example). **But that rule is explicitly conditioned on the vowel being *stressed*** ([[../Sources/Dalmatian|Dalmatian]]'s own stated condition), and NON, functioning as a preverbal proclitic in ordinary speech, never bears independent phrasal stress — the same well-documented cross-linguistic pattern that lets function words escape sound changes their stressed lexical cognates undergo. So NON's ō simply merges to plain /o/ (no diphthong), giving Dalmatian **non** → Sisician **нон**.

**Real Campidanese Sardinian *nono* ("no") is the comparandum that suggested reaching for this word at all** — used the same way Campidanese *dexi*/*noi* were for [[../Words/дешет|дешет]]/[[../Words/ној|ној]]: a typological model, not a claimed ancestor, and not a claim that Sisician's нон is a literal reduced copy of *nono* (its own internal Sardinian derivation — reduplication, suffixation, or something else — wasn't found this session, flagged honestly rather than guessed at). Also worth noting: real attested Dalmatian already has its own cited reflexes of NON — **на, наун** ([[../Etymology/Swadesh List|Etymology/Swadesh List]] item 16's own Dalmatian column) — and нон doesn't replace or contradict those; it's a separate, additional Sisician coinage for a specific pragmatic slot, an aesthetic pick in the same category as [[../Words/штири|штири]] over четири, not a competing derivation of the same word.

## Register

не is closed-class, unmarked, no register coloring. нон is Dalmatian-formal/expressive — the interjection/predicate-adjective slot specifically, per [[../AIOS/memory/project_prestige_register_principle|the prestige-register principle]].

## A Third, Unrelated Negation Item: немој

[[../Grammar/Imperative|Imperative]] (2026-09-25) adds a third negation-related word, **немој(-мо/-те)** — but it isn't a doublet of не or нон, and doesn't extend this page's two-word split. It's a defective, fossilized suppletive auxiliary (не + an old imperative of \*mošti/moći "to be able"), needed specifically because the synthetic imperative can't simply take не- the way an ordinary indicative verb does. See that page for the full account.
