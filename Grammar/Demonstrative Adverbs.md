# Demonstrative Adverbs

See [[Interrogatives]] for the sibling paradigm this directly mirrors (кде/камо/абкле), [[Demonstrative Pronouns]] for the pronoun-side roots this reuses (ов-/т-), and [[../Sisician|Sisician]] for the hub page.

## The Grid

Real Proto-Slavic systematized these place adverbs into a single grid, crossing deictic root against spatial category — confirmed directly from Wiktionary's own navbox template (`Template:sla-pro-adverbs`, the "See also" source behind both [[../Words/кде|кде]]'s and [[../Words/камо|камо]]'s individual pages), not assembled piecemeal:

| | interrogative | proximal (ов-) | medial (т-) | distal (он-) |
|---|---|---|---|---|
| **location** ("where"/"here"/"there") | [[../Words/кде\|кде]] | [[../Words/овде\|овде]] | *tъde — unattested, see below* | *онде — not built* |
| **goal** ("whither"/"hither"/"thither") | [[../Words/камо\|камо]] | [[../Words/овамо\|овамо]] | [[../Words/тамо\|тамо]] | *онамо — not built* |
| **source** ("whence"/"hence"/"thence") | [[../Words/абкле\|абкле]] | [[../Words/одовде\|одовде]] | [[../Words/одтамо\|одтамо]] | *not built* |

**Sisician builds only interrogative, proximal, and medial** — the same two-way (not three-way) deictic system already decided for the demonstrative pronouns ([[Demonstrative Pronouns]] § The System: он-/*онај* stays reserved for the personal pronoun, no distal *онај*/*онде*/*онамо* built). This grid inherits that decision rather than reopening it.

## Two Real Wrinkles This Grid Explains

**Тамо does double duty (location *and* goal) because the medial location slot never survived.** \*Tъde is a real reconstructed Proto-Slavic form, listed in Wiktionary's own grid — but no daughter language actually kept it. \*Tamo (originally goal-only, "thither") generalized to fill the gap, which is why real Serbo-Croatian тамо covers plain "there" today. Sisician inherits this generalization directly rather than needing a separate тъде (see [[../Words/тамо|тамо]] § Etymology).

**Овамо did *not* merge into овде, because the proximal slot's location/goal split is still alive.** Real Serbo-Croatian keeps *ovdje* (location) and *ovamo* (goal) as two distinct living words — unlike тамо's slot, this one didn't collapse. Sisician preserves the same asymmetry: [[../Words/овде|овде]] and [[../Words/овамо|овамо]] stay separate, [[../Words/тамо|тамо]] doesn't have a separate goal-only counterpart because it never needed one.

## The Source Row: A Deliberate Fork From [[Interrogatives]]

The source row forces the same historical choice [[Interrogatives]] § Where, Whither, Whence already made for "whence" — native compositional (**од** + a locative-shaped stem) vs. Latin displacement (**аб** + the same stem). [[../Words/абкле|абкле]] took the Latin-displacement path; the demonstrative pair, **[[../Words/одовде|одовде]]** ("hence") and **[[../Words/одтамо|одтамо]]** ("thence"), were deliberately built on the *other* fork — kept native, at the user's explicit choice, rather than defaulting into the same generalization абкле underwent. This is presented as a real historical asymmetry (two words at the same fork made different choices), not an oversight: nothing has yet motivated Latin AB colonizing the *whole* source-adverb paradigm the way it did the one interrogative word.

**Одтамо's own root choice is a second, smaller departure from the literal Serbo-Croatian cognate**, flagged on its own page: real *odande* ("thence") is built on the distal root (on-), which Sisician doesn't have built. Одтамо instead extends [[../Words/тамо|тамо]] itself — already carrying the full location+goal functional load for "there" — into the source slot too, the same functional-load reasoning already used elsewhere in the vault (e.g. [[Personal Pronouns]]'s ЊЕХ).

## Open Items

- The distal row (онде/онамо/*"thence-yonder"*) is available by the identical mechanism whenever a three-way distance contrast is asked for — same footing as [[Demonstrative Pronouns]]'s unbuilt *онај*.
- Whether Latin AB ever extends further into this paradigm (colonizing одовде/одтамо's slot the way it did абкле's) is an open question, not a rejected one — see [[../Words/абкле|абкле]]'s own still-unresolved "why whence and not которое generalized" question, which the same uncertainty would need to be resolved before extending the pattern.
