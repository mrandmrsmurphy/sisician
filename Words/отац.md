# отац (otac)

**Status: exploratory/tentative.** "Father" — part of the [[../Texts/Pater Noster|Pater Noster]] set, the prayer's opening word (in its vocative fossil **отче**). See [[../Sisician|Sisician]] for the hub page.

## Meaning

"Father" — the ordinary kinship term. [[../Etymology/Semantic Domains|Semantic Domains]] predicts individual kinship terms stay native even where the abstract "family" went Dalmatian ([[../Words/фамаља|фамаља]]), and отац is exactly that prediction confirmed: the word for one's own father is Layer I, warm and unmarked.

**Vocative fossil: отче.** The vocative is fossilized in Sisician (per [[../Grammar/Nominal Morphology|Nominal Morphology]]), and this is its most famous surviving cell — **Отче наш** "Our Father," exactly as real BCS *Oče naš* preserves the same fossil in the same prayer. Kept out of the declension table per the vault's living-forms-only convention; documented here because the prayer uses it.

## Declension (a-declension, soft variant, masculine animate)

| Case | Singular | Plural |
|---|---|---|
| Nominative | отац | отачеви |
| Genitive | отаца | отачева |
| Dative | отацу | отачевима |
| Accusative | отаца (anim. = gen.) | отачева (anim. = gen.) |
| Instrumental | отачем | отачевима |

Two real Croatian patterns copied directly:

- **The ц~ч alternation**: отац but отачеви/отачем — real BCS *otac* → *očevi*/*očem* shows the same ц→ч before the soft endings' е. The vault's first instance of this morphophonemic alternation (distinct from the phonemic ć/đ→č/j merger, which is a different, older event).
- **The soft-stem -ев- plural extension** (ц is in the soft trigger set, per [[../Grammar/Declension Classes|Declension Classes]]): отачеви, not †отацеви — the same -ев- real Croatian shows in *muževi*, *kraljevi*, already confirmed for [[../Words/респонџ|респонџ]].

Animate: accusative = genitive in both numbers, per the general Slavic rule already behind [[../Words/њега|њега]] and [[../Words/дом|дом]]'s animacy split.

## Etymology

**Proto-Slavic \*otь̀cь** "father, patriarch" — an early agent noun from native \*otъ "father" + \*-ьcь ([Wiktionary \*otьcь](https://en.wiktionary.org/wiki/Reconstruction:Proto-Slavic/ot%D1%8Cc%D1%8C), which also lists the vocative **\*otьče** directly). **Fall of the Jers** ([[../Etymology/Fall of the Jers|Fall of the Jers]]): the root ь is strong (followed by the weak suffix jer) and vocalizes to **a**; the suffix jer is weak and drops. \*otьcь → \*otacь → **отац**, matching real Serbo-Croatian *òtac* exactly. The vocative **отче** continues \*otьče with the ordinary first palatalization (c→ч before e), the same shape real BCS *oče* shows.

## Register

Native, unmarked, [[../Etymology/Semantic Domains|Semantic Domains]] Layer I (kinship). In the prayer it appears only in the vocative fossil, which is liturgical register by usage but native in origin — the prayer's opening word is a native Slavic word, not a learned import.
