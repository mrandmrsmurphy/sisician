# коју (koju)

**Status: exploratory/tentative.** Feminine singular accusative of [[који]] — the relative's object case with a feminine antecedent. See [[../Grammar/Relative Clauses|Grammar/Relative Clauses]]. See [[../Sisician|Sisician]] for the hub page.

## Meaning

"Which (feminine singular, as object)?" — interrogative, and relative "whom, that" with a feminine antecedent in an object role: **ел гужва коју сијам** "the crowd that I shine upon." The feminine accusative is always коју — the animate/inanimate split that reshuffles the masculine accusative ([[../Words/кога|кога]]/који) is a masculine-only rule, per the general pattern already established on [[../Words/њега|њега]]/[[../Words/дом|дом]].

## Etymology

**кој- stem + -у**, the feminine accusative ending of the same demonstrative-ending family (-у already established on [[../Words/ту|ту]] and [[../Words/њу|њу]]). No sound change applies; real BCS *koju* matches.

## Register

Closed-class grammatical vocabulary, both uses productive.

## Related

[[који]], [[која]], [[које]] — the feminine paradigm cells. [[../Words/ту|ту]] — the same -у ending on the demonstratives.
