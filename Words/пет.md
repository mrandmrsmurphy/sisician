# пет (pet)

**Status: exploratory/tentative.** See [[../Grammar/Numerals|Grammar/Numerals]] for the full paradigm. See [[../Sisician|Sisician]] for the hub page.

## Meaning

"Five." No gender distinction.

## Etymology

**Proto-Slavic \*pętь → пет, a direct application of the already-established ę→e denasalization** ([[../Words/ме|ме]]/[[../Words/те|те]]'s own mechanism) — no fork between Croatian and Slovene at all, both show *pet* unmodified.

## Register

Closed-class grammatical vocabulary, same status as every other numeral entry.
