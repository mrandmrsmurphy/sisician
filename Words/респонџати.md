# респонџати (respondžati)

**Status: exploratory/tentative — the vault's first `Words/` page for a verb.** No verb had been individually coined before this one, despite the grammar side ([[../Grammar/Verbal Categories|Verbal Categories]], [[../Grammar/Verb Paradigm (Sketch)|Verb Paradigm (Sketch)]], etc.) being extensively sketched — see [[../AIOS/memory/reference_word_entry_format|reference_word_entry_format]]'s new verb extension, established here. See [[../Words/респонџ|респонџ]] for the noun "answer" built directly from this verb's own stem, and [[../Sisician|Sisician]] for the hub page.

## Meaning

"To answer, to respond" — the ordinary verb of giving a reply, replacing native **одговорити** (from **од-** "back" + **говорити** "to speak," a transparent native compound). Structurally, the replacement is almost a wash: Latin **RESPONDĒRE** is itself **RE-** "back" + **SPONDĒRE** "to promise, pledge" — both languages independently built "answer" from a *back- + speak/pledge* compound, a real coincidence worth noting rather than a designed parallel.

## Conjugation (a-type, present tense)

Following [[../Grammar/Verb Paradigm (Sketch)|Verb Paradigm (Sketch)]]'s гледати model exactly — the productive, default class for borrowed verbs, matching real Croatian's own overwhelming preference for **-ати** as the landing class for loanword verbs (*šopati*, *faksati*, and virtually every modern borrowing).

**Stress: root-anchored**, on **-спон-** throughout (респо́нџати, респо́нџам, etc.), not the first syllable **ре-** — matching real Classical Latin RESPONDEŌ's own stress (re-spon-DĒ-ō, penult, heavy long ē) and continuing the same pattern already established for [[../Words/денајр|денајр]] (stress on *-на-*, not *де-*) and [[../Words/фамаља|фамаља]] (stress on *-ма-*, not *фа-*): a multisyllabic Latin borrowing keeps its own inherited stress position, which is essentially never the initial syllable for this kind of word.

This word's root beginning with /r/ makes it a second real test of what happens when the fused је-clitic meets an /r/-initial root — and the answer is **metathesis, not plain clustering**: /j/+/r/ is a sonority-violating onset (glides outrank liquids), so it repairs to /r/+/j/ (рјеспо̀нџао, not †јреспо̀нџао), while /s/+/r/ needs no repair (already sonority-rising) and stays as среспо̀нџали. **Spelled in plain lowercase throughout, not capitalized mid-word** — an earlier draft of this page and of [[../Grammar/Past Tense Fusion and Evidentiality|Past Tense Fusion and Evidentiality]] capitalized the fused element (ЈРА̀дио-style) as a documentation aid, but no real orthography marks a morpheme boundary that way; the grave accent alone carries the actual stress information. See that page § "Second Worked Example" for the full Sonority Sequencing account.

Imperative, aorist/imperfect, Future I/II, pluperfect, and conditional forms all remain open for every Sisician verb, per [[../Grammar/Verb Paradigm (Sketch)|Verb Paradigm (Sketch)]]'s own "Explicitly Not Yet Built" list — not a gap specific to this word.

## Etymology

**Built on a real attested word, the same evidentiary situation as [[../Words/читвот|читвот]] and [[../Words/монајта|монајта]].** Real Vegliote Dalmatian **respondro**, a verb meaning "to answer/respond," cited on Wiktionary as a descendant of Latin **respondeō** (RESPONDĒRE, "re-" + "spondēre" "to promise"). Not independently re-derived step-by-step from Latin — taken as real attested Dalmatian data and built forward from, the way *cituot* and *monaita* were.

**The new step, introducing a genuinely different mechanism from every Cj-cluster rule already on [[../Sources/Dalmatian|Sources/Dalmatian]]**: *respondro*'s **-dr-** (stop + rhotic, syllabifying as re-spon-**dro**) has no yod anywhere near it — this isn't a consonant+glide cluster at all, so none of the already-established NJ/LJ/TJ/KJ/DJ/GJ/SJ/ZJ/RJ rules apply. Instead, this uses a separate, real, cross-linguistically documented mechanism: **rhotic-triggered affrication of alveolar stop+r onset clusters** — the same phenomenon independently attested for English *tr*/*dr* (*train*, *dragon*, pronounced with real affricate-like onsets close enough to /tʃ/-/dʒ/ that some dialects merge *train*/*chain*). Applying it to Dalmatian's own **dr**: **respon-dro → respon-džo**. See [[../Sources/Dalmatian|Sources/Dalmatian]] § "Decided: TR/DR Affricate to č/dž" for the full citation and the honestly-flagged extra step (dropping the residual /r/ that real English keeps).

**Sisician-side adaptation**: the borrowed Dalmatian infinitive (Romance-shaped, ending in *-o*) is re-suffixed with the native Slavic infinitive marker **-ти**, landing the borrowed stem **респонџ-** in the productive **a-type** conjugation class — the default, unmarked landing class for a loanword verb, per real Croatian's own overwhelming practice. Final unstressed *-o* is simply replaced by the native ending, not separately apocopated first (unlike [[../Words/денајр|денајр]]'s own final-vowel loss, which had no native suffix waiting to take its place).
