# три (tri)

**Status: exploratory/tentative.** Invariant — see [[../Grammar/Numerals|Grammar/Numerals]] for the full paradigm. See [[../Sisician|Sisician]] for the hub page.

## Meaning

"Three." No gender distinction, matching real Croatian and Slovene alike (both already invariant for this number).

## Etymology

**Proto-Slavic \*trьje → три directly** — the single jer (ь) is weak (rightmost, word-medial before the reducing -je ending) and drops; the *-je* ending itself reduces regularly. No Croatian/Slovene fork: both languages already agree on *tri* unmodified.

## Register

Closed-class grammatical vocabulary, same status as every other numeral entry.
