# име (ime)

**Status: exploratory/tentative.** "Name" — part of the [[../Texts/Pater Noster|Pater Noster]] set: **да се свети име твој** "let thy name be hallowed." Fills [[../Etymology/Swadesh List|Etymology/Swadesh List]] item 207, the last row of the list. See [[../Sisician|Sisician]] for the hub page.

## Meaning

"Name." An old neuter noun — per the neuter merger it takes **masculine singular** agreement, which is why the prayer's possessive is **твој** (masculine singular), not †твоје: **име твој**, where real BCS and the Slavonic both have the neuter-looking *твоје* (име твоје / имѧ твоѥ). This is one of the small places the prayer sounds distinctly Sisician rather than generically Slavic.

## Declension (a-declension, hard variant)

| Case | Singular | Plural |
|---|---|---|
| Nominative | име | имена |
| Genitive | имена | имена |
| Dative | имену | именима |
| Accusative | име | имена |
| Instrumental | именом | именима |

- **The oblique stem extends with -ен-** (име → имена/имену/именом), the real BCS *ime* → *imena* pattern copied directly.
- **Genitive plural имена is syncretic with nominative plural** (real BCS *imena* likewise); same flagged choice as [[../Words/небо|небо]]'s небеса.

## Etymology

**Proto-Slavic \*jьmę** — already gathered on [[../Etymology/Swadesh List|Swadesh List]] item 207 (OCS имѧ, Serbo-Croatian име, Slovene *ime*). Two steps, both established: South Slavic loses the initial j- (\*jьmę → \*imę — the same j-loss real BCS *ime* and Slovene *ime* both show), then **ę→e denasalization** ([[../Etymology/Sisician Sound Changes|Sisician Sound Changes]] § 2): \*imę → **име**. The Dalmatian cell on the same row (*naum*, < Latin *nōmen*) was not borrowed.

## Register

Native, unmarked, [[../Etymology/Semantic Domains|Semantic Domains]] Layer I. In the prayer it is the object of the hallowing — ordinary vocabulary in a liturgical frame.
