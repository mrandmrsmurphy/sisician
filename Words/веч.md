# веч (več)

**Status: exploratory/tentative.** Coined to answer a real typological gap surfaced by [[../Texts/Conlang Syntax Test Cases|Conlang Syntax Test Cases]] item 5 ("The sun has been shining"): Slavic has no direct equivalent to the English present perfect continuous, and real Croatian/Serbian instead reaches for ordinary present tense + **већ** ("already") — confirmed via search, e.g. real *živim ovdje već dvije godine* "I've been living here for two years," literally "I already live here two years." See [[../Sisician|Sisician]] for the hub page.

## Meaning

"Already" — marks that a state or action, framed as ongoing in the present, in fact started earlier than the moment of speaking. Not a tense or aspect marker in its own right; it does the grammatical work English assigns to the present perfect continuous by adverbially reframing an ordinary present-tense statement.

## Etymology

**Common Slavic \*vęťь, inherited directly.** Three already-established mechanisms apply in sequence, none new:

1. **ę → e** (denasalization) — the same general Common Slavic nasal-vowel loss already used for [[../Words/ме|ме]]/[[../Words/те|те]]: \*vęťь → *vetjь.
2. **tj → ч** (jotation, plus Sisician's own already-decided ć→č merger) — the identical environment behind свеча, ноч, and the -če deverbal-noun allomorph ([[../Words/бити|биче]]): *vetjь → *večь.
3. **Weak yer drop** — the word's one yer (word-final, hence weak by Havlík's Law) vanishes via ordinary [[../Etymology/Fall of the Jers|Fall of the Jers]]: *večь → **веч**.

Real Croatian/Serbian **већ** continues the identical Common Slavic root, just without the ć→č merger — the same relationship [[../Words/бити|биче]] has to real *biće*.

## Register

Native, unmarked, [[../Etymology/Semantic Domains|Semantic Domains]] Layer I — closed-class grammatical/functional vocabulary, the same tier as [[../Words/не|не]], no register coloring.
