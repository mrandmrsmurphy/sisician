# дом (dom)

**Status: exploratory/tentative — see note at bottom.** Part of the [[каза]] / [[дом]] / [[скинија]] / [[икос]] set illustrating the [[../Etymology/Semantic Domains|three-layer lexical model]] for "home/house." See [[../Sisician|Sisician]] for the hub page. Follows the format set by [[../AIOS/memory/reference_word_entry_format|reference_word_entry_format]] (see [[каза]] for the template itself).

## Meaning

Home, house — the ordinary, everyday word. Carries the *cozy*, intimate warmth of English "home" rather than the neutral-to-formal register of English "house" or "residence."

## Declension (a-declension, masculine)

Following real Croatian a-declension (*grad/grada/gradu/grad/gradom*, plural *gradovi*-type) exactly — see [[../Grammar/Nominal Morphology|Nominal Morphology]] for the case system this reflects and [[../Grammar/Declension Classes|Declension Classes]] for the class itself.

| Case | Singular | Plural |
|---|---|---|
| Nominative | дом /ˈdom/ | домови /ˈdomovi/ |
| Genitive | дома /ˈdoma/ | домова /ˈdomova/ |
| Dative | дому /ˈdomu/ | домовима /ˈdomovima/ |
| Accusative | дом /ˈdom/ | домове /ˈdomove/ |
| Instrumental | домом /ˈdomom/ | домовима /ˈdomovima/ |

Two real Slavic-inherited features worth calling out (neither is a Sisician invention):

- **Accusative = Nominative in the singular.** дом is inanimate, and Slavic inanimate masculine nouns take accusative identical to nominative (animate masculine nouns instead take accusative = genitive — a real, general Slavic animacy distinction to keep in mind for future words, not something specific to this one).
- **The plural stem extends with *-ov-*** (дом → домови, not †дом-и), matching the real Croatian pattern for most monosyllabic masculine nouns (*grad→gradovi*, *sin→sinovi*, *zub→zubovi*). дом's monosyllabic root is exactly the environment this applies in.

**Stress: root-anchored** (the general noun rule — see [[../Phonology/Modern Inventory|Modern Inventory]] § Prosody). Every form above, including the four-syllable домовима, keeps stress on the root **до-**, never migrating into the *-ov-* extension or the case endings — matching real Croatian pronunciation of exactly this word-type (*grad → grádovi*, stress-initial, not *gra-dó-vi*). This word was the second data point (after [[каза]]'s казама) that settled root-anchoring as the general rule for nouns.

## Etymology

Common Slavic ***domъ*** "house, home" — a real, inherited Indo-European word (cognate with Latin *domus*, itself the ultimate source of English "domestic," "domicile" — the resemblance to [[каза]]'s own Latin ancestor *casa* is a coincidence of etymology, not a sign of contact). Reaches [[../Sources/Late Common Slavic|Late Common Slavic]] unchanged; **домъ → дом** per the [[../Etymology/Fall of the Jers|Fall of the Jers]] (always followed — see that page for the rule itself). No other established sound change touches this word.

## Register

**Native Slavic, unmarked, warm.** Belongs to [[../Etymology/Semantic Domains|Etymology/Semantic Domains]]'s "Native Slavic" layer — household, ordinary life. Per [[../Grammar/Word Order and Register|Word Order and Register]], expect дом to appear disproportionately in plain SVO constructions, since that syntactic register is itself coded as native/homey — the opposite pairing from [[каза]]'s expected freer-order/fronted contexts.
