# тамо (tamo)

**Status: exploratory/tentative.** "There" — the medial locative-demonstrative adverb, built on the demonstrative root **та-** (a bare-vowel grade of the same root behind [[../Words/тај|тај]] "that") fused with the fossilized adverbial suffix already cited on [[../Words/камо|камо]]'s own page. Fills [[../Etymology/Swadesh List|Etymology/Swadesh List]] item 10. See [[../Sisician|Sisician]] for the hub page.

## Meaning

"There" — location away from the speaker (and, historically, motion toward that location — see Etymology). Contrasts with [[../Words/овде|овде]] "here" the same way [[../Words/тај|тај]] "that" contrasts with [[../Words/овај|овај]] "this."

## Etymology

**Proto-Slavic \*tamo is confirmed via Wiktionary, composed of the root \*ta + the Proto-Slavic adverbial suffix \*-mo** ("From *ta + *-mo"), tracing back through Proto-Balto-Slavic \*tas to PIE \*só. **This is the exact citation [[../Words/камо|камо]]'s own page already invoked** ("real Slavic *tamo 'thither' shows the identical suffix opposing *tu 'here', the exact same relationship камо has to кде") — тамо fulfills a comparandum this vault had already named but not yet built into its own word page. No jer, no fork: both root and suffix are full vowels throughout, so **ta + mo = тамо** falls out directly, matching real Proto-Slavic *tamo and modern Serbo-Croatian тамо letter-for-letter.

**A genuine wrinkle worth flagging rather than smoothing over: тамо's root is \*ta, not \*tъ.** [[../Words/тај|тај]] is built on the jer-final masculine root \*tъ (requiring the *jь-suffixation mechanism to survive at all — see that page's own Etymology). \*Tamo instead continues \*ta, the same already-full-vowel root that gives feminine [[../Words/та|та]] directly (see [[../Grammar/Demonstrative Pronouns|Grammar/Demonstrative Pronouns]] § Etymology — the feminine singular "never needed [jь-suffixation], because [its] Proto-Slavic form[ was] already full-vowel-final"). So тамо isn't morphologically "тај + a suffix" the way овде reads as "ов- (овај's root) + -de" — it's built on the *other* available grade of the same demonstrative root family, one that happens to also survive independently as та. This is real, attested Slavic root-ablaut texture (the masculine/feminine split already visible in *tъ/*ta themselves), not an invented irregularity.

**Semantic drift, inherited rather than invented:** Wiktionary glosses \*tamo as "there; thereto" — historically a directional/goal form ("to there"), the same kind of fossilized directional suffix already established on [[../Words/камо|камо]] "whither." Real modern Serbo-Croatian generalized this originally-directional form to cover plain locative "there" as well (the sense this word carries in Sisician) — the identical directional→locative generalization камо's own suffix underwent, just completed rather than left at the directional stage. Sisician inherits the modern, generalized sense directly rather than re-deriving it.
