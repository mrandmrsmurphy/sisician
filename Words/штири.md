# штири (štiri)

**Status: exploratory/tentative.** The one deliberate Slovene-lean pick in the numeral set — see [[../Grammar/Numerals|Grammar/Numerals]] for the full paradigm. See [[../Sisician|Sisician]] for the hub page.

## Meaning

"Four." No gender distinction.

## Etymology

**Proto-Slavic \*četyre gives real Croatian четири and real Slovene штири** — a genuine, well-known Slavic-internal divergence (č- vs š-), not fully explained even in comparative sources (possibly analogical contamination, unresolved). Sisician adopts the **Slovene-shaped штири**, the same design move already made for [[../Words/јаз|јаз]] (chosen over Croatian-standard *ja*) — a small, individually motivated exception within the vault's own 85%-BCS-baseline calibration, not a systemic shift toward Slovene.

## Register

Closed-class grammatical vocabulary, same status as every other numeral entry.

## Related

[[три]], [[пет]] — the neighboring numerals, both unforked.
