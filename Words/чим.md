# чим (čim)

**Status: exploratory/tentative.** Oblique cell borrowed for [[кај]] — see [[../Grammar/Interrogatives|Grammar/Interrogatives]] for the full paradigm. See [[../Sisician|Sisician]] for the hub page.

## Meaning

"By what?"/"with what?" — instrumental, filling the oblique slot [[кај]] never developed its own form for. **Unlike [[цем]], this cell stayed regular** — it keeps the same ч- stem as its own nominative/genitive/dative, no suppletion here.

## Etymology

**Proto-Slavic \*čimь → чим directly** (final ь weak, drops) — confirmed via the same *čьto declension fetch used for [[чега]]/[[чему]]. Real modern Croatian *čime/čim* matches closely, no releveling needed the way [[кога]]/[[чега]] required.

## Register

Closed-class grammatical vocabulary, no register coloring.

## Related

[[кај]] (nominative/accusative), [[чега]] (genitive), [[чему]] (dative). [[цем]] — the "who" instrumental, which *did* suppletive-shift where this one didn't.
