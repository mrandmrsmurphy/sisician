# камо (kamo)

**Status: exploratory/tentative.** "Whither" — see [[../Grammar/Interrogatives|Grammar/Interrogatives]] § Where, Whither, Whence. Fills part of the where/whither/whence trio (not itself a standalone Swadesh item). See [[../Sisician|Sisician]] for the hub page.

## Meaning

"Whither?"/"to where?" — goal, motion toward. Contrast [[кде]] (static location) and [[абкле]] (source).

## Etymology

**Proto-Slavic \*kamo, a genuinely separate root from *kъde — not built compositionally from it.** Confirmed via Wiktionary as its own distinct etymological entry. Its own **-mo** ending is the same kind of ancient fossilized directional suffix [[кде]]'s **-de** is — real Slavic *tamo* ("thither") shows the identical suffix opposing *tu* ("here"), the exact same relationship камо has to кде. No jer, no fork, adopted directly.

## Register

Closed-class grammatical vocabulary, no register coloring.

## Related

[[кде]] — the location counterpart, same fossilized-case-suffix pattern, different suffix. [[абкле]] — the source counterpart, built (historically) compositionally rather than fossilized, though its own original native prefix has since been replaced by a Latin one. [[../Words/тамо|тамо]] — the demonstrative word built on this exact same -mo suffix and the exact real Slavic *tamo this page already cited as камо's own comparandum, now actually built. [[../Words/овамо|овамо]] — камо's proximal-demonstrative counterpart ("hither"), same suffix family, real Wiktionary-attested *ovъ+*-mo composition.
