# ју (ju)

**Status: exploratory/tentative.** Thirty-eighth individual pronoun entry — the short/clitic counterpart to [[њу]], and, like every other 3rd-person clitic in this set, the bare continuation of the root without the prothetic n- that only ever attaches to full/stressed forms.

## Meaning

The unstressed second-position clitic covering accusative for feminine "her," per [[../Grammar/Personal Pronouns|Personal Pronouns]]'s table — the accusative counterpart to [[је]] (genitive), a genuinely separate word from that one, not a variant of it, per [[ње]]/[[њу]]'s own already-established genitive/accusative split.

## Etymology — Nothing New to Derive

**[[њу]]'s own page already worked out everything this word needs**, and it transfers directly: ју continues Proto-Slavic **\*jǫ** — the same root as [[њу]] — without the prothetic n-, per the clitics-never-take-njь- pattern already confirmed across every 3rd-person cell built so far ([[га]], [[је]], [[их]], [[му]], [[јој]], [[им]]). The back-nasal-vowel denasalization ***ǫ→u*** that produces [[њу]]'s own vowel applies identically here, since it's the same historical vowel in the same morphological slot — repeated rather than re-derived, the same discipline already used for [[те]] inheriting [[ме]]'s denasalization reasoning.

**The one thing worth restating rather than silently assuming:** [[њу]]'s page flagged Slovene's real accusative as *njo* (not the expected *nju*) as an honest unresolved wrinkle. Slovene's own clitic is ***jo***, matching its own stressed form's unexpected vowel — meaning that branch's peculiarity is consistent between its full and short forms, not a split complication the way [[јој]]'s own comparative check found for Slovene's dative pair. Worth noting as a point of *contrast* with [[јој]], not another instance of the same kind of gap.
