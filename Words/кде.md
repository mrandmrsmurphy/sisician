# кде (kde)

**Status: exploratory/tentative.** "Where" — see [[../Grammar/Interrogatives|Grammar/Interrogatives]] § Where, Whither, Whence for the fossilized-case-suffix framing this word shares with [[камо]]. Fills [[../Etymology/Swadesh List|Etymology/Swadesh List]] item 13. See [[../Sisician|Sisician]] for the hub page.

## Meaning

"Where?" — static location. Contrast [[камо]] (goal/motion-to) and [[абкле]] (source/motion-from).

## Etymology

**Proto-Slavic \*kъde is confirmed via Wiktionary to be historically \*kú- (the interrogative stem) + an ancient PIE locative suffix, \*-dʰe** — case is genuinely fossilized into this word's own etymology, opaque and frozen, the same way English "where" itself fossilizes an old instrumental. The single jer (ъ) is the word's only jer and hence weak, dropping regularly, giving **k+de = кде**.

**Deliberately kept k-initial**, per the user's own explicit request, rather than the k→g voicing shift real Croatian/Russian both independently show (*gdje*/*где*) — a real, sporadic, word-specific development in those languages that Sisician simply doesn't undergo.

## Register

Closed-class grammatical vocabulary, no register coloring.

## Related

[[камо]] — the same fossilized-suffix pattern, goal rather than location. [[абкле]] — built (historically) from this word's own oblique-shaped material, where case becomes live rather than fossilized; the native prefix that once stood there has since been replaced by Latin, but this word's own -кле stem survives inside it.
