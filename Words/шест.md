# шест (šest)

**Status: exploratory/tentative.** See [[../Grammar/Numerals|Grammar/Numerals]] for the full paradigm. See [[../Sisician|Sisician]] for the hub page.

## Meaning

"Six." No gender distinction.

## Etymology

**Proto-Slavic \*šestь → шест directly** — the single word-final jer (ь) is trivially weak and drops, the same [[../Words/дом|дом]]-type trivial case. No Croatian/Slovene fork: both languages show *šest* unmodified.
