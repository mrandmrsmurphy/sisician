# том (tom)

**Status: exploratory/tentative.** Instrumental singular feminine of [[та]] — see [[../Grammar/Demonstrative Pronouns|Grammar/Demonstrative Pronouns]] for the full paradigm. See [[../Sisician|Sisician]] for the hub page.

## Meaning

"With that (one)" — instrumental singular feminine of [[та]].

## Etymology

**Proto-Slavic \*tojǫ → том**, matching the identical -ом ending already established on [[../Words/он|он]]'s own feminine instrumental њом and [[../Grammar/Adjective Agreement|Adjective Agreement]]'s нувом. **Same unresolved *e→o vowel history already flagged on [[../Words/њом|њом]] and [[../Words/њој|њој]]** (reconstruction points to an *e*-colored ending; real Serbo-Croatian shows *o* instead, with no source found explaining the shift) — inherited as the identical open question, not re-litigated here. Matches real Serbo-Croatian *tȏm* exactly.

## Register

Closed-class grammatical vocabulary, same status as every other pronoun entry.

## Related

[[та]] (nominative), [[тој]] (dative), [[ту]] (accusative). [[овом]] — the proximal counterpart, same unresolved vowel history.
