# тој (toj)

**Status: exploratory/tentative.** Dative singular feminine of [[та]] — see [[../Grammar/Demonstrative Pronouns|Grammar/Demonstrative Pronouns]] for the full paradigm. See [[../Sisician|Sisician]] for the hub page.

## Meaning

"To that (one)" — dative singular feminine of [[та]].

## Etymology

**Proto-Slavic \*toji → тој**, matching the identical -ој ending already established on [[../Words/он|он]]'s own feminine dative њој and [[../Grammar/Adjective Agreement|Adjective Agreement]]'s нувој — the same "pronominal genitive/dative-singular-feminine ending family" already flagged on [[../Words/ње|ње]]'s page, showing up a third time. Matches real Serbo-Croatian *tȏj* exactly.

## Register

Closed-class grammatical vocabulary, same status as every other pronoun entry.

## Related

[[та]] (nominative), [[те]] (genitive), [[ту]] (accusative), [[том]] (instrumental) — та's paradigm. [[овој]] — the proximal counterpart.
