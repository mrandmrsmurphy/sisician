# којим (kojim)

**Status: exploratory/tentative.** Instrumental singular masculine of [[који]] — and, by the demonstrative-parallel three-way syncretism, the plural dative/instrumental of both genders. See [[../Grammar/Relative Clauses|Grammar/Relative Clauses]]. See [[../Sisician|Sisician]] for the hub page.

## Meaning

- "With/by which (masculine singular)?" — the instrumental relative role: **средство, којим сијам** "the means by which I shine" (with the built word [[../Words/сијати|сијати]]).
- Plural dative/instrumental: "to/with which (pl.)?" — the same syncretism [[../Words/тим|тим]] documents for the demonstratives.

## Etymology

**кој- stem + -им**, the pronominal instrumental ending of the established -ога/-ому/-им/-их family. No sound change applies; real BCS *kojim* matches.

## Register

Closed-class grammatical vocabulary, both uses productive.

## Related

[[који]], [[кога]]/[[којега]] (genitive), [[кому]]/[[којему]] (dative) — the paradigm's masculine cells. [[../Words/тим|тим]] — the same three-way syncretism on the demonstratives.
