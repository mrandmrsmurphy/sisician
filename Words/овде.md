# овде (ovde)

**Status: exploratory/tentative.** "Here" — the proximal locative-demonstrative adverb, built on the same **ов-** root as [[../Grammar/Demonstrative Pronouns|Grammar/Demonstrative Pronouns]]'s [[../Words/овај|овај]] "this," fused with the same fossilized locative suffix already established on [[../Words/кде|кде]] "where." One cell of [[../Grammar/Demonstrative Adverbs|Grammar/Demonstrative Adverbs]]'s full location/goal/source grid — read that page for how this word relates to [[../Words/овамо|овамо]]/[[../Words/тамо|тамо]]/[[../Words/одовде|одовде]]/[[../Words/одтамо|одтамо]]. Fills [[../Etymology/Swadesh List|Etymology/Swadesh List]] item 9. See [[../Sisician|Sisician]] for the hub page.

## Meaning

"Here" — static location near the speaker. Contrasts with [[../Words/тамо|тамо]] "there" the same way [[../Words/овај|овај]] "this" contrasts with [[../Words/тај|тај]] "that" — the same proximal/medial deictic split carried over from the pronoun system into the adverb system.

## Etymology

**Proto-Slavic \*ovъde is confirmed via Wiktionary, composed of the demonstrative root \*ov- (the same root already behind [[../Words/овај|овај]]) plus the fossilized locative suffix \*-de** — the identical suffix family already established on [[../Words/кде|кде]] "where" (*kъde = ku- + PIE locative \*-dʰe). Wiktionary's own comparative table places \*ovъde directly alongside \*kъde, \*sьde, and \*onъde as siblings in the same "place (in)" paradigm, confirming the -de element is a genuinely shared, reusable suffix across this whole word-family rather than word-specific.

**The single jer resolves exactly as it does in [[../Words/кде|кде]]:** \*ovъde has one jer (ъ), not word-final (the suffix -de follows it), and — per the same reasoning already applied on кде's own page — it is the word's only jer and hence weak, dropping regularly. **ov + de = овде**, matching real Old Church Slavonic овъде and modern Serbo-Croatian овде/овдје exactly, not independently re-derived.

**Deliberately built on \*ov- rather than the competing Proto-Slavic alternate \*sьde** (a separate root, historically the ancestor of Russian *сей*-type demonstratives) — Sisician never built a paradigm from that root for "this" either (see [[../Grammar/Demonstrative Pronouns|Grammar/Demonstrative Pronouns]]), so staying on ov- keeps овде consistent with the already-decided pronoun system rather than introducing an unrelated root purely for the adverb.

## Register

Closed-class grammatical vocabulary, same as [[../Words/кде|кде]]/[[../Words/камо|камо]] and the demonstrative pronouns — no Slavic/Dalmatian/Greek stratification applies.

## Related

- [[../Words/тамо|тамо]] — the medial counterpart ("there"), same -suffix mechanism, different fossilized ending and different root grade.
- [[../Words/овај|овај]] — shares the ов- root; овде is this same demonstrative stem doing locative-adverb duty rather than pronominal duty.
- [[../Words/кде|кде]] — shares the -de suffix; кде's own page already names \*ovъde/\*sьde/\*onъde as its comparative siblings, so this word fulfills a citation already made in the vault rather than introducing a new one.
- [[../Words/овамо|овамо]] — the proximal *goal* counterpart ("hither"), same ов- root, kept as a genuinely separate word rather than folded into овде, matching real Serbo-Croatian's own *ovdje*/*ovamo* split.
- [[../Words/одовде|одовде]] — the proximal *source* counterpart ("hence"), built compositionally from this very word (од + овде).
