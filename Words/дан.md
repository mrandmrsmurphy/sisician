# дан (dan)

**Status: exploratory/tentative.** "Day" — part of the [[../Texts/Pater Noster|Pater Noster]] set via its derived adverb [[../Words/данас|данас]] "today" (the prayer's дьньсъ). Fills [[../Etymology/Swadesh List|Etymology/Swadesh List]] item 178. See [[../Sisician|Sisician]] for the hub page.

## Meaning

"Day" — the calendar day, daylight time. The prayer itself uses only the adverb данас, but the noun is the base word and fills the Swadesh row.

## Declension (a-declension, hard variant, masculine)

| Case | Singular | Plural |
|---|---|---|
| Nominative | дан | дани |
| Genitive | дана | дана |
| Dative | дану | данима |
| Accusative | дан (inan. = nom.) | дане (inan.) |
| Instrumental | даном | данима |

**No -ов- plural extension** — дани, not †данови. This is a genuine exception to the monosyllabic-root pattern [[../Words/дом|дом]] follows, copied directly from real BCS *dan* → *dani* (not †*danovi*): the extension is conditional, not automatic, and this word is one of the real conditions where it fails. Inanimate: accusative = nominative.

## Etymology

**Proto-Slavic \*dьnь** — already gathered on [[../Etymology/Swadesh List|Swadesh List]] item 178 (OCS дьнь, Serbo-Croatian дан, Slovene *dan*). **Fall of the Jers** ([[../Etymology/Fall of the Jers|Fall of the Jers]]): the root ь is strong (followed by the weak final jer) and vocalizes to **a**; the final ь drops. \*dьnь → **дан**, matching real BCS *dan* exactly. The Dalmatian cell on the same row (*dai*, < Latin *diēs*) was not borrowed.

Native, unmarked, [[../Etymology/Semantic Domains|Semantic Domains]] Layer I (time vocabulary).
