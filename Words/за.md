# за (za)

**Status: exploratory/tentative.** Static "behind" with instrumental, motion "to behind" with accusative; whence is [[../Words/иза|иза]]. See [[../Grammar/Case Government|Case Government]] for the system and [[../Sisician|Sisician]] for the hub page.

## Meaning

**+ instrumental** = "behind" (where); **+ accusative** = "to behind" (whither). The whence cell is the compound [[../Words/иза|иза]] + genitive, completing a where/whither/whence set (see [[../Grammar/Case Government|Case Government]] § Location Expressions). This alternation was never locative-based, so the locative's loss did not touch it.

**за also takes accusative for "for"** (purpose, exchange, benefit) and **genitive for "during the time of"** — so it governs three cases, the genitive sense temporal rather than spatial.

## Government

| Case | Sense | Example |
|---|---|---|
| Instrumental | behind | **за домом** "behind the house" |
| Accusative | to behind | **за дом** "to behind the house" |
| Accusative | for (purpose, exchange, benefit) | **за тебе** "for you" |
| Genitive | during the time/reign of | (real BCS *za vrijeme rata* "during the war") |

## Etymology

Common Slavic **\*za**. No sound change applies.

## Register

Closed-class grammatical vocabulary — outside [[../Etymology/Semantic Domains|Semantic Domains]]' three-layer model, the same footing as [[../Words/одовде|одовде]].
