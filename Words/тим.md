# тим (tim)

**Status: exploratory/tentative.** A genuinely three-way syncretism, not a simple single-cell word — see [[../Grammar/Demonstrative Pronouns|Grammar/Demonstrative Pronouns]] § Full Case Paradigm for how it fits alongside [[тога]]/[[тому]]. See [[../Sisician|Sisician]] for the hub page.

## Meaning

Fills **three** grammatically distinct cells with one form, confirmed directly against the real Serbo-Croatian declension table rather than assumed: masculine singular instrumental of [[тај]] ("with that"), and — separately — the plural dative *and* plural instrumental, shared across both genders ("to/with those"). Real Serbo-Croatian shows exactly this same three-way convergence (*tȋm* masc.sg.instr. = *tȉm* plural dat./instr.), so this isn't an artifact of the Sisician derivation — it's inherited.

## Etymology

**Two historically separate Proto-Slavic forms converging on one modern shape, the same kind of real inherited syncretism already normalized throughout this vault** (cf. [[../Words/каза|каза]]'s dat.pl.=instr.pl., [[../Grammar/Personal Pronouns|Personal Pronouns]]'s њима). Masculine singular instrumental continues **\*těmь**; plural dative continues **\*těmъ**; plural instrumental continues **\*těmi** — three distinct Proto-Slavic endings, all confirmed via Wiktionary's *tъ declension table, that regularly converge to one Sisician form. **The *-im (not the Ekavian-expected *-em) vowel is adopted directly from real Serbo-Croatian usage**, the same already-established analogical ending as [[../Words/он|он]]'s њим and [[../Grammar/Adjective Agreement|Adjective Agreement]]'s нувим — flagged honestly as inherited texture rather than independently derived, matching the standard this vault already holds itself to for [[../Words/нама|нама]]'s and [[../Words/тебе|тебе]]'s own unexplained vowels.

## Register

Closed-class grammatical vocabulary, same status as every other pronoun entry.

## Related

[[тај]], [[тога]], [[тому]] — singular paradigm siblings. [[тих]] — the plural genitive counterpart. [[овим]] — the proximal twin, same three-way syncretism.
