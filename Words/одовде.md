# одовде (odovde)

**Status: exploratory/tentative.** "Hence" — the proximal *source* adverb, completing the location/goal/source grid alongside [[../Words/овде|овде]] (location) and [[../Words/овамо|овамо]] (goal). Built compositionally, native throughout — the road *not* taken by [[../Words/абкле|абкле]] "whence," which took the Latin-displacement path instead. Not itself a standalone [[../Etymology/Swadesh List|Etymology/Swadesh List]] item, the same non-Swadesh status as [[../Words/камо|камо]]/[[../Words/овамо|овамо]]. See [[../Sisician|Sisician]] for the hub page.

## Meaning

"Hence"/"from here" — source, motion away from the speaker's location. Contrasts with [[../Words/овде|овде]] (location) and [[../Words/овамо|овамо]] (goal) the same way [[../Words/кде|кде]]/[[../Words/камо|камо]]/[[../Words/абкле|абкле]] contrast for the interrogative set — completing the same three-way grid one deictic degree over.

## Etymology

**Compositional: од ("from") + [[../Words/овде|овде]] ("here").** Native **од** is the ordinary preposition already regularly governing genitive in the living case system (per [[../Grammar/Nominal Morphology|Nominal Morphology]]'s source→genitive rule, already established via [[../Words/абкле|абкле]]'s own etymology) — trivially inherited, no fresh derivation needed. Fusing it onto an already-built locative adverb is the identical mechanism native Common Slavic used for "whence" too (**од + -кле**, the etymon [[../Words/абкле|абкле]] historically replaced) — the difference here is that this compositional form is kept as the modern word rather than being displaced, a deliberate choice made explicitly to avoid extending [[../Words/абкле|абкле]]'s own Latin-displacement trajectory to the whole source-adverb paradigm without a specific historical motivation for doing so.

**Real comparandum, imperfect match flagged honestly:** real Serbo-Croatian *odavde* ("hence") is built the same way, od- + a locative "here"-word — though Wiktionary's own entry for it leaves the etymology unresolved (marked "please add"), and the real attested form shows a further vowel change (*od-av-de*, not the transparent *od-ov-de* this word gives) that has no citable mechanism behind it. **Одовде stays at the transparent, uncontracted compositional stage** rather than forcing an uncited contraction to match — a plainer, more conservative derivation than its real-world cognate, not a re-derivation of it.

No cluster or devoicing complication: **д** is followed by the vowel **о**, not a voiceless consonant, so none of the regressive-devoicing machinery [[../Words/абкле|абкле]]/[[../Words/одтамо|одтамо]] need applies here.

## Register

Closed-class grammatical vocabulary, same as [[../Words/кде|кде]]/[[../Words/камо|камо]]/[[../Words/абкле|абкле]] and the demonstrative-adverb set — no Slavic/Dalmatian/Greek stratification applies.
