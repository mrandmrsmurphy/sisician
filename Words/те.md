# те (te)

**Status: exploratory/tentative.** Thirteenth individual pronoun entry — the exact 2sg structural twin of [[ме]], the way [[тебе]] was already the twin of [[мене]]. See [[../Grammar/Personal Pronouns|Grammar/Personal Pronouns]] and [[../Grammar/Clitic Ordering|Clitic Ordering]] for the systems this word plugs into, and [[../Sisician|Sisician]] for the hub page.

## Meaning — The Same Story as ме, One Person Over

те is [[тебе]]'s short/enclitic counterpart, covering both genitive and accusative — and, exactly as [[ме]]'s page worked out for 1st singular, **this isn't just an inherited copy of тебе's syncretism.** [[тебе]]'s page already confirmed Proto-Slavic kept genitive **\*tȅbe** and a separate accusative-only enclitic, ***\*tę̑***, not carried forward here as an independent full form. те is where *\*tę̑* actually survives — realized directly, then **extended to cover genitive too**, the same real modern-South-Slavic syncretism already documented on [[ме]]'s page, now shown for the second person rather than being a 1st-singular-specific quirk.

## Etymology

**Directly continues Proto-Slavic \*tę̑, via the same sound change already used for [[ме]] — not re-derived independently.** [[тебе]]'s page already flagged the fetched *ty* declension table's separate accusative enclitic, ***\*tę̑***, ancestor of Old Church Slavonic **тѧ** (tę). This is the exact same nasal vowel, in the exact same morphological slot, as 1st-singular *\*mę̃* — so **the same regular South Slavic denasalization (ę→e) already discussed on [[ме]]'s page applies here without needing a fresh citation**: *\*tę̑* → **те**. Repeating rather than re-verifying that sound change is a deliberate choice, not a shortcut — it would be a coincidence needing its own explanation if the *identical* vowel in the *identical* slot behaved differently one person over.

**The genitive extension is the same real syncretism as [[ме]]'s, not a separate event.** Old Church Slavonic's тѧ was accusative-only, exactly paralleling мѧ; modern South Slavic vernaculars generalized both 1st- and 2nd-singular accusative clitics to also cover genitive, symmetrically. Sisician inherits this already-generalized modern pattern for те the same way it did for [[ме]].

**Real Slavic comparanda (accusative/genitive clitic):**

| Branch | Language | Form |
|---|---|---|
| South Slavic (liturgical) | Old Church Slavonic | тѧ (tę, accusative-only; no genitive clitic) |
| South Slavic | Serbo-Croatian | te (accusative and genitive clitic, both) |
| South Slavic | Slovene | te |
| South Slavic | Bulgarian | те (te) |
| East Slavic | Russian | тебя survives only as the full form; no distinct short clitic in the standard language |
| West Slavic | Polish | cię (retains the nasal, the expected *t*→*ci* palatalization aside); ciebie as the modern oblique full form |

**Same branch contrast as [[ме]], not a new one:** Polish's retained nasal (*cię*) again confirms те reflects the South Slavic denasalized outcome specifically — the identical point [[ме]]'s page already made for 1st singular, now holding symmetrically for 2nd. No revision needed.

## Register — Clitic Placement, Not Just Informality

Per [[../Grammar/Clitic Ordering|Clitic Ordering]], те is a true second-position (Wackernagel) clitic, exactly like [[ме]] — not an "unstressed casual variant" of тебе. Full тебе is required after a preposition and for contrastive emphasis; те is required in ordinary second-position clitic contexts. When ме and те would ever compete for the same clitic slot in a sentence with both a 1st- and 2nd-singular object, [[../Grammar/Clitic Ordering|Clitic Ordering]]'s fixed relative ordering (not this page) is what resolves it.
