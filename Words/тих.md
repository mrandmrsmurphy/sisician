# тих (tih)

**Status: exploratory/tentative.** Plural genitive of [[тај]]/[[та]], shared across both genders — see [[../Grammar/Demonstrative Pronouns|Grammar/Demonstrative Pronouns]] for the full paradigm. See [[../Sisician|Sisician]] for the hub page.

## Meaning

"Of those" — genitive plural, ungendered, matching the general "plural oblique cases don't distinguish gender" pattern already established for [[../Words/њих|њих]]/[[../Grammar/Adjective Agreement|Adjective Agreement]]'s нувих.

## Etymology

**Proto-Slavic \*těxъ → тих**, the identical -их ending family already established on [[../Grammar/Adjective Agreement|Adjective Agreement]]'s нувих and [[../Words/он|он]]'s plural њих. **The *-ix (not Ekavian *-ex) vowel is adopted directly from real Serbo-Croatian *tȋh*, the same honestly-flagged inherited-texture category as [[тим]]'s own vowel**, not independently derived.

## Register

Closed-class grammatical vocabulary, same status as every other pronoun entry.

## Related

[[тим]] — the plural dative/instrumental counterpart. [[ових]] — the proximal twin.
