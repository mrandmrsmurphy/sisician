# ове (ove)

**Status: exploratory/tentative.** Feminine plural counterpart to [[овај]] — see [[../Grammar/Demonstrative Pronouns|Grammar/Demonstrative Pronouns]] for the full paradigm. See [[../Sisician|Sisician]] for the hub page.

## Meaning

"These" (feminine referents) — and, parallel to [[те]]/[[../Words/оне|оне]], the true landing site for old-neuter-plural proximal reference, per [[../Grammar/Nominal Morphology|Nominal Morphology]]'s neuter merger.

**Added 2026-09-23, two further cells of the same paradigm — ordinary syncretism, not a new word:** ове is also the **genitive singular** of [[ова]] ("of this") and the **plural accusative**, both genders, of [[овај]]/[[ова]]. Confirmed directly against the real Serbo-Croatian declension table (fem. genitive *òvē* = plural accusative *òvē* = plural fem. nominative *òvē*, all identical) — the exact structural twin of [[те]]'s own three-way syncretism one paradigm over, and the same "expect real inherited homophony" category already normalized on [[../Words/каза|каза]].

## Etymology

**Proto-Slavic \*ovy (fem.nom.pl. and plural accusative, both genders) → ове, via the same old pronominal/adjectival plural \*-y→\*-ě (yat) merger** already used for [[те]] and [[../Words/оне|оне]] — confirmed via Wiktionary's *ovъ reconstruction (which lists *\*ovy* directly as the feminine/accusative plural) and cross-checked against real Serbo-Croatian's attested *òvē*.

**The genitive-singular cell is a separate historical source converging on the same spelling**, exactly paralleling [[те]]: Proto-Slavic feminine genitive singular **\*ovoję̇** — the same pronominal genitive-singular-feminine ending family already behind [[../Words/ње|ње]], [[те]]'s own genitive sense, and [[../Grammar/Adjective Agreement|Adjective Agreement]]'s нуве — regularly reduces to **ове** as well, matching real Serbo-Croatian's *òvē* exactly. Two distinct Proto-Slavic sources, one modern form, the identical pattern [[те]] already documents.
