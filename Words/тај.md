# тај (taj)

**Status: exploratory/tentative.** First demonstrative-pronoun entry, opening [[../Grammar/Demonstrative Pronouns|Grammar/Demonstrative Pronouns]]'s paradigm — read that page first for the shared mechanism this word and its five siblings ([[та]], [[ти]], [[те]], [[овај]], [[ова]], [[ови]], [[ове]]) all rest on. Fills [[../Etymology/Swadesh List|Etymology/Swadesh List]] item 8 ("that"). See [[../Sisician|Sisician]] for the hub page.

## Meaning

"That" — the **medial** demonstrative (near the addressee, or simply "not this one"), contrasting with [[овај]] "this." Per [[../Grammar/Nominal Morphology|Nominal Morphology]]'s neuter merger, **тај also covers every old-neuter-singular referent** — the same landing site [[../Words/он|он]] already established for the personal pronoun (see that page's own § Meaning for the full reasoning); there is no separate "that (thing)" form.

## Etymology

**Proto-Slavic \*tъ (masc.nom.sg.) + \*jь (anaphoric-pronoun suffix) → тај.** Confirmed via Wiktionary: real Serbo-Croatian *taj* is "inherited from Proto-Slavic *tъ + *jь." The same suffix independently already established on [[../Words/он|он]]'s oblique stem (њега/њему) and [[../Grammar/Adjective Agreement|Adjective Agreement]]'s long-form нув(и) — this word is simply a third, previously-unbuilt application of it.

**The mechanism, worked through via [[../Etymology/Fall of the Jers|Fall of the Jers]]:** a bare *\*tъ* is a monosyllabic word-final jer — by Havlík's Law it's trivially the rightmost jer, hence weak, hence it would simply vanish if left unsuffixed (leaving an unpronounceable bare *t-*). Suffixing *\*jь* changes the count: the suffix's own jer (*ь*) is now rightmost and weak (drops), which makes the **root's** jer (*ъ*) the next one leftward — no longer final, hence **strong**, hence it vocalizes to the South Slavic outcome **a** (per [[../Etymology/Fall of the Jers|Fall of the Jers]]'s own stated ъ/ь→a rule). The suffix's onset consonant *j* survives (it's a consonant, not the dropped vowel). Result: **t + a + j = тај** — matching real Serbo-Croatian *tȃj* exactly, not coincidentally.

**No new sound change introduced** — this derivation combines three already-established facts (Havlík's Law, the *jь*-suffixation mechanism, the South Slavic a-outcome) for the first time, rather than requiring a fresh one.

## Register

Closed-class grammatical vocabulary — no Slavic/Dalmatian/Greek stratification applies, same status as [[../Words/он|он]]/[[../Words/ти|ти]]/[[../Words/јаз|јаз]].
