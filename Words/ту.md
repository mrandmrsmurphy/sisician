# ту (tu)

**Status: exploratory/tentative.** Accusative singular feminine of [[та]] — see [[../Grammar/Demonstrative Pronouns|Grammar/Demonstrative Pronouns]] for the full paradigm. See [[../Sisician|Sisician]] for the hub page.

## Meaning

Accusative singular feminine of [[та]] — "that (one)" as a direct object.

**A future-collision risk worth flagging:** [[../Etymology/Swadesh List|Etymology/Swadesh List]] item 9 ("here") lists Proto-Slavic *\*tu* as one of its own real comparanda (distinct from this word's *\*tǫ*, but identical once denasalized and spelled) — if "here" is ever coined from that root, it would land on the same spelling. Worth a future builder checking this page first.

## Etymology

**Proto-Slavic \*tǫ (accusative singular feminine) → ту**, via the same *ǫ→u denasalization already established on [[../Words/њу|њу]] (*jǫ→њу) and cross-checked against Polish's retained nasal (*ą*) — the identical mechanism, third application. Matches real Serbo-Croatian *tȗ* exactly.

## Register

Closed-class grammatical vocabulary, same status as every other pronoun entry.
