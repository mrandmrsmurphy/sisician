# абкле (abkle)

**Status: exploratory/tentative.** A genuine hybrid calque that fully displaced its own native predecessor — see [[../Grammar/Interrogatives|Grammar/Interrogatives]] § Where, Whither, Whence, and [[../Etymology/Sisician Sound Changes|Sisician Sound Changes]] § Prestige-Driven Lexically-Specific Developments, which this word extends with a new subtype. See [[../Sisician|Sisician]] for the hub page.

## Meaning

"Whence?"/"from where?" — source, motion away from. **The sole modern word** — there is no living register doublet; the native predecessor it replaced (see Etymology) no longer has an independent `Words/` entry, the same "superseded intermediate stage, not a separate coexisting word" treatment already given to дешет's own десет.

## Etymology

**A genuine hybrid formation, historically a legal/notarial curiosity that fully generalized — a two-stage history, not a single event.** Native Common Slavic built "whence" compositionally, **од** ("from," regularly governing genitive) + **-кле**, an oblique-shaped element related to [[кде]]'s own material (matching real Croatian *odakle*'s own makeup) — this earlier stage is no longer independently attested as its own word, only as the etymon абкле replaced.

**Stage 1 (Middle Sisician, c. 1150–1350):** Latin **AB** ("from") entered through the same written legal/notarial Latin channel already motivating [[куи]] ([[../Culture/Sociolinguistic History|Culture/Sociolinguistic History]]'s "Latin survives... in diplomatic/foreign-trade/family-document contexts"), fusing onto the native oblique stem **-кле** in place of native **од** — a genuine hybrid calque, one morpheme from each ancestry in a single word, proposed directly by the user as "a fun... calque mixture." At this stage it was a legal-register curiosity, confined the way [[куи]] still is.

**Stage 2 (Early Modern Sisician, c. 1350–1650):** unlike [[куи]], абкле didn't stay confined — it generalized out from the legal/notarial register to fully displace the native compositional form in ordinary speech, the same trajectory [[../Words/ној|ној]] took displacing native девет. **Why "whence" and not "which" generalized while the other stayed confined** is an open question, not yet given its own historical account — flagged honestly rather than papered over.

**The case-marking story survives the replacement, which is the real point of this word's history:** the preposition slot changed (native од → Latin аб), but the native, genitive-shaped oblique stem **-кле** stayed constant across the change — case marking in "whence" was never tied to which specific preposition occupied that slot, only to the grammatical relationship (preposition governing an oblique-shaped stem) itself.

**Spelling vs. pronunciation:** written **абкле**, but б before the voiceless к regressively devoices — pronounced **[apˈkle]**, the same Sava-corridor devoicing pattern already cited on [[../Sources/Late Common Slavic|Late Common Slavic]] (*v kući → f kući*).

## Register

Historically Dalmatian-formal/legal (per frontmatter), but — unlike [[куи]] — doesn't stay there. By the modern stage it's simply the ordinary word, carrying no more register weight than [[../Words/дешет|дешет]] or [[../Words/ној|ној]] do.
