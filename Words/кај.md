# кај (kaj)

**Status: exploratory/tentative — first Words/ page for the vault's own defining dialect marker.** See [[../Grammar/Interrogatives|Grammar/Interrogatives]] for the full who/what suppletive paradigm. Fills [[../Etymology/Swadesh List|Etymology/Swadesh List]] item 12. See [[../Sisician|Sisician]] for the hub page.

## Meaning

"What?" — the single most recognizable Kajkavian marker (the dialect is literally named for it), already decided as Sisician's own vernacular form back on [[../Sources/Late Common Slavic|Late Common Slavic]] § Dialect Zone. This page is the first time it gets an actual `Words/` entry, cited etymology, and a place in the wider grammar.

## Etymology

**Proto-Slavic \*kъjь → кај directly, via the identical Havlík's Law mechanism already behind [[тај]]/[[овај]]:** the word-final jь's own ь is weak and drops; the non-final ъ is strong and vocalizes to the South Slavic outcome **a**; the suffix's *j* consonant survives. Result: **k+a+j = кај** — a bare, frozen, non-declining substantivized form. **Real modern Croatian *koji* ("which") shares this exact same root** — see [[који]] — but reflects further suffixation Kajkavian's own *kaj* never underwent, so the two don't collide despite the shared ancestry.

**Never developed its own oblique case paradigm** (it stayed frozen as a single invariant form) — see [[чега]]/[[чему]]/[[чим]] for where "what"'s oblique cells actually come from instead.

## Register

Closed-class grammatical vocabulary, and specifically the vernacular/unmarked form — no Dalmatian or Greek stratification applies.

## Related

[[кто]] — the parallel "who" pronoun, same historical paradigm family. [[који]] — the same root, further suffixed. [[закај]] — за+кај, "why," a free consequence of this word already existing.
