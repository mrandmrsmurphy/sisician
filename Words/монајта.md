# монајта (monajta)

**Status: exploratory/tentative.** The narrower, concrete counterpart to [[../Words/денајр|денајр]] "money" (abstract), coined alongside it. Like [[../Words/читвот|читвот]], built directly on a real attested Dalmatian citation rather than an in-vault re-derivation. See [[../Sisician|Sisician]] for the hub page.

## Meaning

"Coin, cash" — the concrete medium (an actual coin, physical currency), distinct from [[../Words/денајр|денајр]]'s abstract "money" (wealth, currency as a concept). No native register doublet; not part of the same displacement story as денајр (Proto-Slavic **\*skotъ** is displaced by денајр specifically — see that page — not by this word, which fills a semantic slot the native lexicon may never have needed a dedicated word for at all).

## Declension (e-declension, feminine)

Following [[../Words/каза|каза]]'s e-declension pattern exactly, per [[../Grammar/Declension Classes|Declension Classes]]'s standing rule that Dalmatian *a*-final loans land in e-declension.

Same inherited syncretisms as каза, for the same reason: nom.sg. **монајта** = gen.pl. **монајта**; gen.sg. **монајте** = nom.pl./acc.pl. **монајте**; dat.pl. = instr.pl. **монајтама**.

**Stress: root-anchored**, on **-нај-** throughout (moˈnaj.ta, moˈnaj.te, moˈnaj.ta.ma) — the position real Vegliote *monaita* itself already stresses, carried over unchanged.

## Etymology

**Built on a real attested word, the same evidentiary situation as [[../Words/читвот|читвот]].** Real Vegliote Dalmatian **monaita** "coin," cited directly on Wiktionary (`en.wiktionary.org/wiki/monaita`) among the real Romance descendants of Latin **MONĒTA** (alongside Italian *moneta*, Sicilian *munita*, Friulian *monede*, and the word ultimately behind English *money* and *mint* themselves, via Anglo-Norman). Latin MONETA is feminine (an epithet of Juno, "the Warner/Adviser," whose temple housed Rome's mint — the word for "money" descends from the *place*, not a coin-shape or metal), matching real Italian/French feminine outcomes.

**The internal Latin→Dalmatian derivation is not independently re-derived here, and for the same honest reason [[../Sources/Dalmatian|Sources/Dalmatian]] already flags for *cituot*.** MONETA's stressed vowel (in classical *mo-NĒ-ta*) would, under this vault's existing ē-diphthongization rule, be expected to give **ie** (open syllable → monophthongizes to *i*), not the **ai** real *monaita* actually shows. This is now the *second* real Dalmatian word (after *cituot*'s own unexplained *a→uo*) whose attested vowel outcome doesn't fit the existing Stage 1/Stage 2 model — **recorded here as a second data point for the same open item on [[../Sources/Dalmatian|Sources/Dalmatian]]**, not resolved. No yod-metathesis explains it either (MONETA has no *i*-before-vowel sequence anywhere to metathesize). Taken as real, attested surface data and built forward from, the same methodology already used for *cituot*.

**The rest is straightforward Sisician-side adaptation**, no new mechanism needed: real *monaita*'s own [aj]-type diphthong is spelled with Sisician's established **ј** (monaita → монајта), the same respelling [[../Words/денајр|денајр]] needed for its own metathesis-derived diphthong; feminine *-a* final lands directly in e-declension, per [[../Words/каза|каза]]'s own already-confirmed pattern for Dalmatian *a*-final loans.
