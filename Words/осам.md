# осам (osam)

**Status: exploratory/tentative.** See [[../Grammar/Numerals|Grammar/Numerals]] for the full paradigm. See [[../Sisician|Sisician]] for the hub page.

## Meaning

"Eight." No gender distinction.

## Etymology

**Proto-Slavic \*osmь → real Croatian osam / real Slovene osem — the exact same a/e epenthetic-vowel divergence as [[седам]], same page, one number over.** Croatian-shape adopted as the default, same honest "inherited, not derived" treatment.

## Register

Closed-class grammatical vocabulary, same status as every other numeral entry.
