# јутро (jutro)

**Status: exploratory/tentative.** Coined for [[../Texts/Conlang Syntax Test Cases|Conlang Syntax Test Cases]] item 7 ("The sun will shine tomorrow"). See [[../Sisician|Sisician]] for the hub page.

## Meaning

Two senses in one word: the noun "morning," and the bare adverb "tomorrow." This is the German pattern — *morgen* is both "morning" and "tomorrow" — and the user's own decision: no prefix, no separate lexeme for "tomorrow."

An old neuter noun — per [[../Grammar/Nominal Morphology|Nominal Morphology]]'s neuter merger, takes **masculine singular** agreement and **feminine plural** agreement, the same as [[../Words/сунце|сунце]].

**Adverbial use:** the bare nominative/accusative singular, **јутро**, used without a preposition, means "tomorrow." There is no fused \*sъ jutra type (Croatian *sutra*); [[../Words/с|с]] + genitive would just be a transparent "off of the morning."

## Declension (a-declension, hard variant)

| Case | Singular | Plural |
|---|---|---|
| Nominative | јутро | јутра |
| Genitive | јутра | јутара |
| Dative | јутру | јутрима |
| Accusative | јутро | јутра |
| Instrumental | јутром | јутрима |

Hard stem, so instrumental singular is **-ом** (not soft **-ем**). Plural nominative/accusative is the inherited neuter collective **-a**; genitive plural takes the filler vowel (**јутара**) by the same functional-load reasoning as [[../Words/сунце|сунце]]'s сунаца, since bare јутра would otherwise be identical to genitive singular and nominative/accusative plural. See [[../Grammar/Declension Classes|Declension Classes]] § The Neuter Plural.

## Etymology

**Proto-Slavic \*jutro** ("morning"), inherited directly. No jers, nasals, or yat anywhere in it, so none of the established changes ([[../Etymology/Fall of the Jers|Fall of the Jers]], denasalization, yat reflex) apply — it comes through unchanged.

**The initial *j-* is kept**, spelled **ј** (U+0458), as in [[../Words/један|један]] (\*(j)edьnъ) and real BCS *jutro*. The vault has no rule dropping initial /j/ before /u/, so the retained form is the default; if a rule is ever added, this word is a test case.

**Semantic path "morning" → "tomorrow"** is cross-linguistically ordinary and attested within Slavic: Polish *jutro*, Slovene *jutri*, Bulgarian/Macedonian *утре* mean "tomorrow" (bare); Croatian/Serbian *sutra* and Czech *zítra* are the same word with a preposition fused on (\*sъ jutra, "from morning"); Russian *завтра* and Slovak *zajtra* add \*za. Outside Slavic, German *morgen* and English *to-morrow* show the same shift. Sisician takes the bare type, which both avoids reproducing Croatian *sutra* exactly (see [[../AIOS/memory/project_distancing_from_slavic_neighbors|the distancing thread]]) and avoids a fused preposition that would sit awkwardly beside the still-live [[../Words/с|с]].

Native, unmarked, [[../Etymology/Semantic Domains|Semantic Domains]] Layer I — ordinary everyday vocabulary.
