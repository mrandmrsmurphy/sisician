# дочи (dochi)

**Status: exploratory/tentative.** "To come, arrive" — part of the [[../Texts/Pater Noster|Pater Noster]] set: **да доје царство твој** "let thy kingdom come." See [[../Sisician|Sisician]] for the hub page.

## Meaning

"To come, arrive" — perfective by inheritance: one bounded arrival, not an ongoing approach. The imperfective partner **долазити** (real BCS *dolaziti*) is unbuilt, flagged rather than coined here per the standing aspect-pair policy. In the prayer it appears in the jussive perfective present (**да доје**), matching the Slavonic's own да придетъ — "let it come," a single expected event.

## Etymology

**\*do- + \*jьti** "to go" — the same compound that gives real BCS **доћи / дође** ([Wiktionary доћи](https://en.wiktionary.org/wiki/%D0%B4%D0%BE%D1%9B%D0%B8), fetched: perfective, imperfective долазити, from до- + ћи). **Derivation:** run through the vault's own Kajkavian baseline merger, **ć→č and đ→j** (decided on [[../Sources/Late Common Slavic|Late Common Slavic]], already in the c. 1000 baseline per [[../Etymology/Sisician Sound Changes|Sisician Sound Changes]]): доћи → **дочи**, дође → **доје**. Real Kajkavian *doči/doje*-type forms are the living parallel for exactly this outcome.

**Alternative considered and set aside:** \*jьti → \*jti → дојти/дојде, preserving the glide directly (the real Kajkavian *dojde* type). Rejected as less consistent with the vault's own stated baseline, which already includes the merger — the mechanical outcome of the vault's own rules is дочи/доје, and that is what is built. Flagged openly in case the user prefers the *dojde* shape.
