# ова (ova)

**Status: exploratory/tentative.** Feminine singular counterpart to [[овај]] — see [[../Grammar/Demonstrative Pronouns|Grammar/Demonstrative Pronouns]] for the full paradigm. See [[../Sisician|Sisician]] for the hub page.

## Meaning

"This" (feminine referent) — the feminine singular of the proximal demonstrative. Stays purely a feminine agreement form; old-neuter-singular reference goes to [[овај]] (masculine), not here, the same asymmetric pattern as [[та]]/[[../Words/она|она]].

**Worth flagging, not a collision to fix:** ова is a one-letter minimal pair with [[../Words/она|она]] "she/it" (в vs. н) — the same kind of real, accepted near-homophony this vault already treats as inherited texture rather than a design flaw (see [[../Grammar/Demonstrative Pronouns|Grammar/Demonstrative Pronouns]] § A Real Inherited Homophony for the [[ти]]/[[../Words/ти|ти]] case). Real Serbo-Croatian has the identical *ova*/*ona* near-pair.

## Etymology

**Inherited directly from Proto-Slavic \*ova — no suffixation needed**, the same reasoning as [[та]]: already a full open-vowel nominative in Proto-Slavic itself (confirmed via Wiktionary's *ovъ declension paradigm), unlike the masculine's jer-final *\*ovъ*. Matches real Serbo-Croatian *òvā* exactly.

## Register

Closed-class grammatical vocabulary, same status as every other pronoun entry.

## Related

[[овај]] (masc.), [[ови]] (masc.pl.), [[ове]] (fem.pl.) — ова's own paradigm. [[та]] — the medial counterpart.
