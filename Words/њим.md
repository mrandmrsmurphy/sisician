# њим (njim)

**Status: exploratory/tentative.** Thirty-ninth individual pronoun entry — the instrumental cell of [[он]]'s paradigm, and, with this page, **every cell of [[../Grammar/Personal Pronouns|Personal Pronouns]]'s full table now has its own built `Words/` page.** This closes out a set that began with [[јаз]] and has run continuously since.

## Meaning

"With him" — and, per [[он]]'s own page, also "with it" for any old-neuter-singular referent, the same neuter-merger consequence already fully established there. No clitic exists for this cell; њим covers both stressed and unstressed contexts by itself, matching every other instrumental built in this set ([[мном]], [[тобом]], [[нама]], [[вама]], [[њима]]).

## Etymology — The Cleanest Derivation to Close the Set

**The prothetic-n mechanism is [[он]]'s own** (see that page), applied here the same way it was applied to every other oblique cell of this pronoun.

**Fetched the *jь* masculine singular declension (already used for [[њега]] and [[њему]]'s builds) for its instrumental cell specifically:** it gives **\*jimь**, and — cross-checked directly against real attested Old Church Slavonic text via the same "third personal pronoun" table already used for [[га]] and [[му]]'s builds — OCS's own actual spelling is **имь** (imĭ), confirming the reconstruction with the strongest evidentiary category available in this set (real attested text, not just a reconstruction).

**This is a clean, fully regular derivation, closing the paradigm on solid ground rather than another open question:** the [[../Etymology/Fall of the Jers|Fall of the Jers]] drops the weak final *ь*, giving bare **им** — a real, unbuilt but predictable short form, following exactly the same shape [[../Grammar/Personal Pronouns|Personal Pronouns]]'s table would give it if this paradigm had an instrumental clitic (it doesn't, per the standing confirmation already noted on every other instrumental page). With the prothetic n- attached (the same mechanism, on the same schedule, as every full/stressed 3rd-person form in this set), **им → њим**, cleanly. No vowel puzzle, no unresolved branch tension, no honestly-flagged gap — a genuinely simple ending to a paradigm that included some of this project's hardest etymological questions ([[га]], [[њој]], [[нама]]'s -a vowel).
