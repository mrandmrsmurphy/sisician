# чему (čemu)

**Status: exploratory/tentative.** Oblique cell borrowed for [[кај]] — see [[../Grammar/Interrogatives|Grammar/Interrogatives]] for the full paradigm. See [[../Sisician|Sisician]] for the hub page.

## Meaning

"To what?" — dative, filling the oblique slot [[кај]] never developed its own form for.

## Etymology

**Proto-Slavic \*čemu → чему directly** — no jer, no fork, matches the reconstruction letter-for-letter, the exact parallel of [[кому]] one root over.

## Register

Closed-class grammatical vocabulary, no register coloring.

## Related

[[кај]] (nominative/accusative), [[чега]] (genitive), [[чим]] (instrumental). [[кому]] — the "who" cell this word mirrors exactly.
