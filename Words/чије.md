# чије (čije)

**Status: exploratory/tentative.** Feminine plural of [[чији]] — with the same three-way syncretism as [[које]]: also the feminine singular genitive. See [[../Grammar/Relative Clauses|Grammar/Relative Clauses]]. See [[../Sisician|Sisician]] for the hub page.

## Meaning

"Whose (feminine plural)?" — **даожници, чије казе сијају** "debtors whose houses shine" — and "of which (feminine singular)?" as the genitive relative role. The syncretism is the [[../Words/ове|ове]]/[[које]] pattern one root over, no new mechanism.

## Etymology

**чиј- stem + -е**, the same pronominal *-y→*-ě merger as [[које]] and [[../Words/оне|оне]]. No sound change applies beyond the inherited shape; real BCS *čije* matches.

## Register

Closed-class grammatical vocabulary, both uses productive.

## Related

[[чији]], [[чија]], [[чијих]] (plural genitive). [[које]] — the same syncretism on који.
