# читвот (čitvot)

**Status: exploratory/tentative — and the vault's first word built directly on a real attested Dalmatian citation rather than an in-vault re-derivation from Latin.** See [[../Etymology/Semantic Domains|Etymology/Semantic Domains]] § The Three-Layer Lexical Model, Layer II ("Dalmatian City") — this word is the clean, expected case that model predicts, unlike [[../Words/фамаља|фамаља]]'s deliberate exception to Layer I. See [[../Sisician|Sisician]] for the hub page.

## Meaning

"City." **The sole modern word** — no living native register doublet. The native candidate it displaces, Proto-Slavic **\*gordъ** (real, well-attested — ancestor of Croatian/Serbian *grad*, Russian *город*), was never built as an independent `Words/` page, the same "superseded, not a separate coexisting word" treatment already given to дешет's десет, абкле's одкле, and фамаља's породица/\*obitělь.

**\*gordъ itself isn't necessarily gone from the language entirely** — its real Proto-Slavic sense was broader than "city" to begin with ("enclosure, fortified place," source of real cognates like *ograda* "fence," English *yard*/*garden*/*orchard* via the same PIE root) — only flagged here as an available future word (fortress? enclosed yard?) with a narrower sense, not built now, per the same real Romanian precedent where *cetate* (< CIVITAS!) narrowed to "fortress" specifically while a different word took "city." Not pursued further unprompted.

## Declension (i-declension, feminine, consonant-final)

**The first i-declension word built in this vault** — [[../Grammar/Declension Classes|Declension Classes]] names this class (real Croatian *kost/kosti/kosti/kost/kosti*-type) but had no worked example yet. Built directly from real Croatian i-declension, with one explicit simplification and one explicit real-pattern retention:

| Case | Singular | Plural |
|---|---|---|
| Nominative | читвот /tʃiˈtvot/ | читвоти /tʃiˈtvoti/ |
| Genitive | читвоти /tʃiˈtvoti/ | читвотију /tʃiˈtvotiju/ |
| Dative | читвоти /tʃiˈtvoti/ | читвотима /tʃiˈtvotima/ |
| Accusative | читвот /tʃiˈtvot/ | читвоти /tʃiˈtvoti/ |
| Instrumental | читвоти /tʃiˈtvoti/ | читвотима /tʃiˈtvotima/ |

**Simplification, flagged as a choice, not a citation:** singular instrumental is given as plain **-и** (matching genitive/dative), the modern-colloquial-BCS pattern, rather than the older, still-real Croatian **-ју**-plus-assimilation alternative (*kost+ju → košću*) — which, applied here, would actually hand this word a second real test of the ć→č merger (*читвот+ју* → the т+ј cluster would regularly give ć, which Sisician merges to **ч**, yielding something like *читвочу*). Left unbuilt rather than decided unprompted; flagged as a live, real alternative for this word specifically if a more archaic/literary instrumental is ever wanted.

**Genitive plural extended to -ију, not left as plain -и**, matching real Croatian's own *kostiju*-type extended i-declension genitive plural — the same functional-load motivation already established for [[../Words/сунце|сунце]]'s own genitive-plural filler vowel (*сунаца*): a bare *читвоти* would otherwise collide with genitive singular, dative singular, instrumental singular, *and* nominative/accusative plural all at once, five cells on one shape. **Dative/instrumental plural -има** matches [[../Words/дом|дом]]'s домовима and [[../Words/каза|каза]]'s казама exactly — a real, independently-confirmed fact that all three Croatian declension classes converge on this same plural ending, not a new invention for this word.

**Stress: root-anchored**, on **-тво-** throughout (чиˈтвот, чиˈтвоти, чиˈтвотима, чиˈтвотију) — the position real Vegliote *cituot* itself already stresses (*ci-ˈtuot*), carried over unchanged rather than recomputed.

## Etymology

**Built on a real attested word, not an in-vault re-derivation — a first for this vault, and worth being explicit about the difference.** Every other Dalmatian-derived `Words/` page so far ([[../Words/каза|каза]], [[../Words/фамаља|фамаља]], etc.) starts from Classical/Late Latin and derives forward through [[../Sources/Dalmatian|Sources/Dalmatian]]'s own decided rules. This one starts from a **real, independently attested Dalmatian word**: Vegliote **cituot** /tʃiˈtuot/, "city," cited directly on Wiktionary (`en.wiktionary.org/wiki/cituot`) as descending "from Late Latin *cīvitātem*." Wiktionary's own etymology section gives no intermediate derivation — just the bare Latin source — so the step-by-step path from CIVITATEM to *cituot* isn't independently re-derived here; the attested surface form is taken as the anchor point, the same way [[../Words/каза|каза]] takes real Italian *casa→[ˈkaza]* as its typological anchor rather than re-deriving Italian phonology from scratch.

**This real word corrected two things about [[../Sources/Dalmatian|Sources/Dalmatian]] itself** (2026-09-24, see that page for the full fix): the initial **k→č** (spelled *c* in the Latin transliteration) shows real Dalmatian palatalizes velars before ***i*** specifically — a genuinely distinctive, real, cited fact ("the only Romance language that has palatalised /k/ and /ɡ/ before /i/, but not before /e/," per real linguistic sources) — not the blanket "front vowels always preserved" rule this page previously stated. **A real convergence worth naming, the same category as the ɲ/ʎ overlap already established**: this Dalmatian č lands directly in Sisician's own already-existing native č (from Common Slavic's first palatalization) — no adaptation needed for that consonant at all.

**The Sisician-side step, and the one genuinely new proposal on this page:** real *cituot*'s stressed *-tuot* diphthong contains a /w/-like glide that [[../Phonology/Modern Inventory|Modern Inventory]] has no phoneme for (the same gap already identified for [[../Sources/Dalmatian|Dalmatian]]'s own *mwart* "death," decided 2026-09-20 to harden to /v/). Applying that **already-decided mechanism** — not a new one — to this word's own glide: **cituot [tʃiˈtuot] → читвот [tʃiˈtvot]**. The one difference from *mwart*'s own case: that word's hardening was decided to happen *inside dying Dalmatian itself*, in its final generations (post-1300); this word is placed as an **early** loan (Old Sisician, c. 1000–1150, alongside [[../Words/каза|каза]] — see period, below), so the hardening is presented as happening at the **Sisician-borrowing step** instead, for the same underlying reason (no native /w/ to receive it) rather than a Dalmatian-internal development — the same general principle, applied at an earlier point in the timeline than *mwart*'s.

**The remaining stressed vowel, -a- (in Latin -TĀTE-) → -o- in real *cituot*, is left as real, cited, attested data — see [[../Sources/Dalmatian|Sources/Dalmatian]]'s new "Open Item" section**: it isn't independently re-derived here, since I don't have a reliable, sourced account of *why* real Dalmatian diphthongizes stressed *a* to *uo* (two real attestations exist — *cituot* and *tuota* "father" — but not a worked-out conditioning rule), and inventing one to look tidy would be exactly the overbuilding [[../AIOS/memory/feedback_dont_overbuild_from_examples|feedback_dont_overbuild_from_examples]] warns against.
