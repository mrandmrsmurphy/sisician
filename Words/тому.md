# тому (tomu)

**Status: exploratory/tentative.** Dative singular of [[тај]] — see [[../Grammar/Demonstrative Pronouns|Grammar/Demonstrative Pronouns]] for the full paradigm. See [[../Sisician|Sisician]] for the hub page.

## Meaning

"To that (one)" — dative singular masculine of [[тај]].

## Etymology

**Proto-Slavic \*tomu → тому directly**, continuing the bare root т- with the already-established -ому dative ending (identical to [[../Grammar/Adjective Agreement|Adjective Agreement]]'s нувому and, one paradigm over, [[../Words/он|он]]'s own њему — all three descend from the same *jь-pronoun dative). Matches real Serbo-Croatian *tȍmu* exactly.

## Register

Closed-class grammatical vocabulary, same status as every other pronoun entry.

## Related

[[тај]] (nominative), [[тога]] (genitive), [[тим]] (instrumental). [[овому]] — the proximal counterpart.
