# одтамо (odtamo)

**Status: exploratory/tentative.** "Thence" — the medial *source* adverb, completing the location/goal/source grid alongside [[../Words/тамо|тамо]] (location and, per its own page, goal too). The medial sibling of [[../Words/одовде|одовде]]; see that page first for the shared mechanism and the deliberate choice to stay native rather than follow [[../Words/абкле|абкле]]'s Latin-displacement path. Not itself a standalone [[../Etymology/Swadesh List|Etymology/Swadesh List]] item. See [[../Sisician|Sisician]] for the hub page.

## Meaning

"Thence"/"from there" — source, motion away from a location near the addressee (or simply "not here"). Contrasts with [[../Words/тамо|тамо]], which already covers both location and goal for the medial slot — this word adds the third leg, source, matching [[../Words/абкле|абкле]]'s own relationship to [[../Words/кде|кде]]/[[../Words/камо|камо]] one deictic degree over.

## Etymology

**Compositional: од ("from") + [[../Words/тамо|тамо]] ("there").** Same mechanism as [[../Words/одовде|одовде]] — see that page for the general case (native од regularly governing genitive, per [[../Grammar/Nominal Morphology|Nominal Morphology]], fused onto an already-built place adverb).

**A real, deliberate departure from the literal Serbo-Croatian cognate, flagged rather than papered over.** Real *odande* ("thence") is built on the **distal** root (on-, the same root behind *onde* "there, yonder") — not the medial root this word uses. Sisician never built a distal demonstrative slot at all (see [[../Grammar/Demonstrative Pronouns|Grammar/Demonstrative Pronouns]] § The System — он/*онај* is reserved for the personal pronoun, not extended into a third deictic degree), so there is no Sisician "онde" for од- to attach to. **Attaching од- to [[../Words/тамо|тамо]] instead is the internally consistent choice**, not an arbitrary substitution: тамо already carries the full functional load of Sisician's "there" (location *and* goal, per its own page's noted directional→locative generalization), so extending it to cover the source slot too is the same functional-load logic already used elsewhere in the vault (e.g. [[../Grammar/Personal Pronouns|Personal Pronouns]]'s ЊЕХ), applied here to fill a gap the two-way proximal/medial system created for itself.

**Regressive devoicing, the same mechanism as [[../Words/абкле|абкле]]:** written **одтамо**, but the voiced **д** immediately precedes the voiceless **т**, regressively devoicing (д→[t]) and then simplifying by degemination (the resulting /tt/ collapses to a single [t]) — pronounced **[oˈtamo]**, the same Sava-corridor-type devoicing pattern already cited on [[../Words/абкле|абкле]] and [[../Sources/Late Common Slavic|Late Common Slavic]] (*v kući → f kući*).

## Register

Closed-class grammatical vocabulary, same as [[../Words/кде|кде]]/[[../Words/камо|камо]]/[[../Words/абкле|абкле]] and the demonstrative-adverb set — no Slavic/Dalmatian/Greek stratification applies.

## Related

- [[../Words/одовде|одовде]] — the proximal source counterpart, same mechanism, no devoicing complication (see that page).
