# овим (ovim)

**Status: exploratory/tentative.** The proximal counterpart to [[тим]], the same three-way syncretism — see [[../Grammar/Demonstrative Pronouns|Grammar/Demonstrative Pronouns]] for the full paradigm. See [[../Sisician|Sisician]] for the hub page.

## Meaning

Fills the same three cells [[тим]] does, one root over: masculine singular instrumental of [[овај]] ("with this"), plus the plural dative *and* plural instrumental, shared across both genders ("to/with these"). Confirmed directly against the real Serbo-Croatian declension table (*òvīm* covers all three cells there too), not assumed by analogy alone.

## Etymology

**Three historically separate Proto-Slavic endings converging on one form**, exactly paralleling [[тим]]: masculine singular instrumental *\*ověmь*, plural dative *\*ověmъ*, plural instrumental *\*ověmi* — confirmed via Wiktionary's *ovъ declension table. **The *-im vowel (rather than the Ekavian-expected *-em) is adopted directly from real Serbo-Croatian usage**, inherited texture matching [[тим]]'s own already-flagged gap, not independently derived.

## Register

Closed-class grammatical vocabulary, same status as every other pronoun entry.

## Related

[[овај]], [[овога]], [[овому]] — singular paradigm siblings. [[ових]] — the plural genitive counterpart. [[тим]] — the medial twin, same three-way syncretism.
