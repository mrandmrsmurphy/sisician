# над (nad)

**Status: exploratory/tentative.** Static "above" with instrumental, motion "to above" with accusative; whence is [[../Words/изнад|изнад]]. See [[../Grammar/Case Government|Case Government]] for the system and [[../Sisician|Sisician]] for the hub page.

## Meaning

**+ instrumental** = "above" (where); **+ accusative** = "to above" (whither). The whence cell is the compound [[../Words/изнад|изнад]] + genitive, completing a where/whither/whence set (see [[../Grammar/Case Government|Case Government]] § Location Expressions). This alternation was never locative-based, so the locative's loss did not touch it.

## Government

| Case | Sense | Example |
|---|---|---|
| Instrumental | above | **над домом** "above the house" |
| Accusative | to above | **над дом** "to above the house" |

## Etymology

Common Slavic **\*nadъ**; the weak final jer drops ([[../Etymology/Fall of the Jers|Fall of the Jers]]).

## Register

Closed-class grammatical vocabulary — outside [[../Etymology/Semantic Domains|Semantic Domains]]' three-layer model, the same footing as [[../Words/одовде|одовде]].
