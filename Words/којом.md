# којом (kojom)

**Status: exploratory/tentative.** Feminine singular instrumental of [[који]]. See [[../Grammar/Relative Clauses|Grammar/Relative Clauses]] for the paradigm. See [[../Sisician|Sisician]] for the hub page.

## Meaning

"With/by which (feminine singular)?" / relative "with/by whom, that": the instrumental relative role with a feminine antecedent — **олоква, којом сијам** "the torch by which I shine" (олоква "torch" not yet built; the role is what this page records). With the built prepositions: **за којом** "after which (f.)," **пред којом** "before which (f.)."

## Etymology

**кој- stem + -ом**, the feminine instrumental of the established family (the same -ом as [[../Words/том|том]]/[[../Words/њом|њом]], instrumental for pronouns where nouns take -ом/-ом — the pronoun ending is identical in shape here). No sound change applies; real BCS *kojom* matches.

## Register

Closed-class grammatical vocabulary, both uses productive.

## Related

[[који]], [[која]], [[којој]] (dative). [[../Words/том|том]] — the same -ом on the demonstratives.
