# колико (koliko)

**Status: exploratory/tentative.** "How much/how many" — see [[../Grammar/Interrogatives|Grammar/Interrogatives]]. Not itself a Swadesh item. See [[../Sisician|Sisician]] for the hub page.

## Meaning

"How much?"/"how many?"

## Etymology

**Proto-Slavic \*koliko → колико directly** — trivial, no fork, both Croatian and Slovene already agree unmodified.
