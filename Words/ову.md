# ову (ovu)

**Status: exploratory/tentative.** The proximal counterpart to [[ту]] — see [[../Grammar/Demonstrative Pronouns|Grammar/Demonstrative Pronouns]] for the full paradigm. See [[../Sisician|Sisician]] for the hub page.

## Meaning

Accusative singular feminine of [[ова]] — "this (one)" as a direct object.

## Etymology

**Proto-Slavic \*ovǫ → ову**, via the same *ǫ→u denasalization already established on [[../Words/њу|њу]] and [[ту]] — the same mechanism, a further application, not a fresh one. Matches real Serbo-Croatian *òvū* exactly.

## Register

Closed-class grammatical vocabulary, same status as every other pronoun entry.

## Related

[[ова]] (nominative), [[овој]] (dative), [[овом]] (instrumental). [[ту]] — the medial counterpart.
