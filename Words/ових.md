# ових (ovih)

**Status: exploratory/tentative.** The proximal counterpart to [[тих]] — see [[../Grammar/Demonstrative Pronouns|Grammar/Demonstrative Pronouns]] for the full paradigm. See [[../Sisician|Sisician]] for the hub page.

## Meaning

"Of these" — genitive plural, ungendered, matching [[тих]]'s own pattern and the general plural-oblique-doesn't-distinguish-gender rule.

## Etymology

**Proto-Slavic \*ověxъ → ових**, the identical -их ending family as [[тих]] and [[../Grammar/Adjective Agreement|Adjective Agreement]]'s нувих. Same inherited *-ix (not Ekavian *-ex) vowel already flagged on [[тих]]. Matches real Serbo-Croatian *òvīh* exactly.

## Register

Closed-class grammatical vocabulary, same status as every other pronoun entry.

## Related

[[овим]] — the plural dative/instrumental counterpart. [[тих]] — the medial twin.
