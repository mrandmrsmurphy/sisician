# опет (opet)

**Status: exploratory/tentative.** Coined for [[../Texts/Conlang Syntax Test Cases|Conlang Syntax Test Cases]] item 6 ("The sun is shining again"), the user's own proposed form and etymology, verified via search this session. See [[../Sisician|Sisician]] for the hub page.

## Meaning

"Again" — repetition of a state or action. Ordinary temporal adverb, no aspectual complication the way [[../Words/веч|веч]] had.

## Etymology

**Common Slavic \*opętь, inherited directly — confirmed via search this session.** Real Croatian/Serbian **опет** continues the identical form (cognate with Czech *opět*, Russian **опять**), itself **\*o- + \*pęta** ("heel") — literally "back on the heel," a real, well-attested semantic path from "heel/footstep" to "back again," not a folk etymology. Only one mechanism needed, already established:

- **ę → e** (denasalization) — the same Common Slavic nasal-vowel loss already used for [[../Words/ме|ме]]/[[../Words/те|те]]/[[../Words/веч|веч]]: \*opętь → *opetь.
- The word's one yer (word-final, hence weak by Havlík's Law) drops via ordinary [[../Etymology/Fall of the Jers|Fall of the Jers]]: *opetь → **опет**.

**No dialect fork to navigate, unlike [[../Words/сунце|сунце]] or [[../Words/сијати|сијати]].** Denasalization itself (unlike a yat reflex) isn't a Croatian-vs-Slovene-vs-Serbian choice point — it happened uniformly across South Slavic — so real Croatian, Serbian, and Slovene all agree on **opet** already, with no Sisician-specific pick to make. This is the fourth word to reuse the ę→e mechanism ([[../Words/ме|ме]], [[../Words/те|те]], [[../Words/веч|веч]], now опет), and the first case among them with no accompanying jotation or vowel fork at all — about as trivial a derivation as this vault has.

## Register

Native, unmarked, [[../Etymology/Semantic Domains|Semantic Domains]] Layer I — ordinary closed-class temporal adverb, same tier as [[../Words/веч|веч]] and [[../Words/не|не]].
