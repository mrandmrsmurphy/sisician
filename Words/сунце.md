# сунце (sunce)

**Status: exploratory/tentative.** The vault's first genuinely soft-stem noun — see [[../Grammar/Adjective Agreement|Adjective Agreement]] § Two Declensions, which already defined the hard/soft split (stems in ц дз ч џ ш ж љ њ ј take soft endings) but had no lexical example until now. Fills [[../Etymology/Swadesh List|Etymology/Swadesh List]] item 147. Prompted directly by [[../Texts/Conlang Syntax Test Cases|Texts/Conlang Syntax Test Cases]] item 1, "The sun shines" — at the time, not translatable (no verb yet), but its subject now existed. **Resolved 2026-09-25**: [[../Words/сијати|сијати]] "to shine" supplies the missing verb — **Сунце сија.**

## Meaning

"Sun." An old neuter noun — per [[../Grammar/Nominal Morphology|Nominal Morphology]]'s neuter merger, takes **masculine singular** agreement ("the sun" pronominalizes as [[../Words/он|он]], not a separate "it") and **feminine plural** agreement in the (rare) plural, the same mechanism already established throughout.

## Declension (a-declension, soft variant)

The **ц**-final stem is exactly the soft-stem trigger set [[../Grammar/Adjective Agreement|Adjective Agreement]] already named — this is the first noun to actually show it, where [[../Words/нув|нув]] only ever demonstrated the hard declension.

| Case | Singular | Plural |
|---|---|---|
| Nominative | сунце | сунца |
| Genitive | сунца | сунаца |
| Dative | сунцу | сунцима |
| Accusative | сунце | сунца |
| Instrumental | **сунцем** | сунцима |

**The soft stem shows up in exactly one cell, the same narrow -o-/-e- alternation already described for adjectives**: instrumental singular **-ем**, not the hard-stem **-ом** [[../Words/дом|дом]] takes. Every other cell is unaffected by the hard/soft split, matching what [[../Grammar/Adjective Agreement|Adjective Agreement]] already predicted before any noun existed to confirm it.

**Corrected 2026-09-23, before this table ever left this page:** an earlier draft of this table had nominative/accusative *plural* as **сунце** (identical to the singular), reasoning from [[../Grammar/Declension Classes|Declension Classes]]'s own claim that neuter plurals "take e-declension plural endings." Real Serbo-Croatian *sunce* (confirmed via Wiktionary) shows plural nominative/accusative **sunca**, not *sunce* — meaning that claim doesn't actually hold up against real data, the first time it's been tested against an actual neuter noun since it was written. The real, simpler story: neuter plural nominative/accusative keeps its **own distinct, genuinely old inherited collective *-a* ending** — not borrowed from e-declension at all — while genitive and dative/instrumental plural happen to coincide with ordinary a-declension's own oblique plural endings (**-а**/-аца, **-има**, the same endings [[../Words/дом|дом]]'s домова/домовима show once its conditional *-ов-* stem extension is set aside). See [[../Grammar/Declension Classes|Declension Classes]] § The Neuter Plural, Corrected, where this fix is generalized.

**Genitive plural takes a functional-load-motivated filler vowel, сунаца rather than bare сунца.** Real Serbo-Croatian attests both *sunaca* (with filler vowel) and *sunca* (without), with no clear preference given in the source consulted. Sisician adopts the filler-vowel form specifically because, without it, genitive plural would be **silently identical** to genitive singular *and* to nominative/accusative plural (all "сунца") — the same [[../Grammar/Personal Pronouns|functional-load principle]] already invoked for [[../Words/њех|њех]]'s own innovation and [[../Words/вас|вас]]'s genitive-for-accusative choice, applied here to justify picking the *more* differentiated real variant instead of inventing one.

## Etymology

**PIE \*sóh₂wl̥ → Common Slavic \*sъlnь + diminutive \*-ьce → сунце**, via a mechanism already implicit in this vault's own data, just never previously named. The **-ъл-** sequence isn't an ordinary jer-plus-consonant cluster — it's a fossilized PIE *syllabic liquid* (confirmed via Wiktionary: *\*sóh₂wl̥* has that same syllabic *l̥* directly), a structurally different case from the full-vowel liquid metathesis already established for [[../Etymology/Sisician Sound Changes|golva→glava]]. Real South Slavic regularly vocalizes this exact syllabic-liquid type straight to **у** — not a one-off rule invented for this word, but the same pattern already sitting uncommented-on in [[../Etymology/Swadesh List|Etymology/Swadesh List]] item 182 ("full," *\*pьlnъ → real Croatian пун) and the comparanda for "wolf" (*\*vьlkъ→vuk*) and "long" (*\*dъlgъ→dug*). Once that vocalizes, the remaining **ь** (of the *-ьce* suffix) is the word's sole surviving jer and trivially weak, dropping via ordinary [[../Etymology/Fall of the Jers|Fall of the Jers]]. Result: **s+u+n+c+e = сунце**, matching real Serbo-Croatian *sȗnce* exactly.

**Real Slovene *sonce* (o, no л at all) was seriously considered and set aside, not overlooked.** Slovene's own regular reflex of this same syllabic liquid is usually **-ol-** (real *volk* "wolf," *dolg* "long," keeping the л) — meaning *sonce*'s л-less shape is an exception even within Slovene's own system, not just a different vowel color, and most plausibly continues a separate real Common Slavic doublet, **\*sъnьce** (without the л), rather than being the same word with a different outcome. Since none of this vault's established "deliberate Slovene lean" picks ([[../Words/јаз|јаз]], [[../Words/штири|штири]]) apply here — no individually-motivated reason to prefer it — сунце (the better-understood, pattern-consistent, Croatian-majority outcome) was chosen instead, per direct user confirmation.

## Register

Native, unmarked, no Dalmatian or Greek stratification — the ordinary word for the sun, not a formal/erudite register slot. [[../Etymology/Swadesh List|Swadesh List]] item 147 also cites Vulgar Latin *\*sol*/*\*soliculus* and Dalmatian *saul*; no Dalmatian-register doublet has been coined for "sun," and none is proposed here.
