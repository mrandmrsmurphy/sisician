# ех (eh)

**Status: exploratory/tentative.** Twenty-third individual pronoun entry — the short/clitic counterpart to [[њех]], and, like that page, built on internal derivation rather than external citation. But ех's own relationship to its full form is genuinely different from every other clitic/full pair in this set, worth stating plainly rather than assumed to be more of the same pattern.

## Meaning

The unstressed second-position clitic covering genitive and accusative for feminine "them," per [[../Grammar/Personal Pronouns|Personal Pronouns]]'s table — [[оне]]'s own genitive/accusative, distinct from masculine's [[их]] since the ЊЕХ innovation.

## Etymology — Not a Reduction, and Not an Old Form Either: Coined Together

**Every other clitic/full pair in this set has a real historical layering to describe** — [[их]]'s page found that их is actually the *older* form and [[њих]] the innovation (n- added later); [[ме]]/[[мене]] and [[те]]/[[тебе]] each trace two genuinely separate Proto-Slavic forms merging or diverging over real centuries. **ех has none of that layering, because it has no history to layer.** [[њех]]'s own page already established that the njeh/ех pair is a pure Sisician-internal coinage, invented in a single design decision (2026-09-19), not something that emerged gradually the way every other pronoun form in this project did.

**What ех actually continues is a stated design principle, not a sound change.** [[../Grammar/Personal Pronouns|Personal Pronouns]]'s page explicitly reversed an earlier draft position on exactly this point: an initial version of that page argued clitics should lag behind stressed-form innovations, being more conservative by nature (which is, notably, exactly what really happened historically for [[их]]/[[њих]]) — but then overturned that for njeh/ех specifically, reasoning that if the whole point of the innovation is disambiguation *in actual speech production*, that need applies at least as much to the high-frequency clitic as to the stressed form. So ех was coined **simultaneously** with njeh, not derived from it afterward and not preserving an older layer the way [[их]] does.

**The shape itself (-ех, not some other vowel) isn't arbitrary** — it directly continues [[њех]]'s own proportional analogy, dropping only the njь- prefix per the same clitics-never-take-njь- generalization already established on [[их]]'s and [[њих]]'s pages:

> [[је]] (fem.sg.gen. clitic) : [[га]] (masc.sg.gen. clitic) :: **ех** (fem.pl.gen. clitic) : [[их]] (masc.pl.gen. clitic)

This is the clitic-level restatement of the same ratio [[њех]]'s page already gave at the full-form level (ње:њега::њех:њих) — not a separate derivation, just the predictable clitic-shaped version of it.

## Register — Clitic Placement

Per [[../Grammar/Clitic Ordering|Clitic Ordering]], ех is a true second-position (Wackernagel) clitic, occupying the same slot as [[их]]/[[ме]]/[[те]]/[[га]]/[[је]]. Full [[њех]] is required after a preposition and for contrastive emphasis; ех takes the ordinary second-position slot otherwise — the same functional split as every other pair in this paradigm, despite being brand-new material.
