# њех (njeh)

**Status: exploratory/tentative.** Twenty-second individual pronoun entry — and the **first pronoun word page in this whole set that isn't primarily a citation of inherited material.** Every pronoun built so far (even [[он]]'s prothetic-n and [[вас]]'s ambiguity-avoidance) ultimately traces a real historical form back through Proto-Slavic. њех doesn't: it's a genuine Sisician-internal coinage, already fully derived on [[../Grammar/Personal Pronouns|Personal Pronouns]]'s own page, and this entry's job is to give that coinage its own word-level home, not to fetch a new citation for it.

## Meaning — Where [[оне]] Actually Diverges from [[они]]

њех is [[оне]]'s own genitive/accusative — the point where the feminine plural pronoun paradigm stops sharing forms with [[они]]/[[њих]] entirely. Every other oblique cell in the feminine plural (dative/instrumental, [[њима]]/[[им]]) remains genuinely shared with masculine, matching the inherited Proto-Slavic pattern where 3rd-plural oblique cases never distinguished gender at all (see [[он]]'s page § Only Two Genders). Genitive/accusative is the *one* place that inherited syncretism was deliberately broken.

## Etymology — Why This Page Has No Proto-Slavic Citation, and What It Has Instead

**Real Proto-Slavic never distinguished 3rd-plural genitive/accusative by gender at all.** [[он]]'s page already established this from the *jь* reconstruction: masculine, feminine, and neuter plural all shared identical oblique forms (*jixъ genitive across all three genders). So there is no historical form for њех to descend from — looking for one would be looking for something that never existed, not an oversight in this session's research.

**What exists instead is a fully-derived internal motivation, already worked out on [[../Grammar/Personal Pronouns|Personal Pronouns]]'s page, repeated here in summary rather than re-derived:**

1. **The root cause:** [[../Grammar/Nominal Morphology|Nominal Morphology]]'s neuter merger removed the pronoun system's only remaining escape hatch for distinguishing "person" from "thing" — the old *on/ona/ono* and *oni/one/ona* nominative-only distinctions. Losing that nominative contrast created real systemic pressure across the *whole* paradigm, even though no oblique case had ever been structurally different to begin with.
2. **Where the pressure resolved — a functional question, not a phonological one:** genitive/accusative (objects and possessors) carry far higher referential/disambiguation traffic in ordinary discourse than dative/instrumental (recipients, means) — the same **functional load** principle already cited on [[вас]]'s page for a different reason entirely. Genitive/accusative had both an available analogical model *and* enough communicative payoff to motivate change; dative/instrumental had the model (singular *њој*/*њом* carry the same *-о-* color as *ње*) but lacked the motivation, and stayed unified.
3. **The actual mechanism: proportional (four-part) analogy**, the standard historical-linguistics tool for paradigm-internal innovation once real motivation exists:

> [[ње]] (fem.sg.gen.) : [[њега]] (masc.sg.gen.) :: **њех** (fem.pl.gen.) : [[њих]] (masc.pl.gen.)

Feminine singular genitive [[ње]] was already the bare, "е-flavored" member of its pair, contrasting with masculine's extended [[њега]] — a live pattern already sitting in the paradigm, not invented for this specific purpose. Extending that same ratio to the plural, using [[њих]]'s own already-established -их ending as the model, produces -ех for feminine: **њех**.

4. **Accusative joins genitive rather than getting a separate derivation** because they were already historically syncretic (real Croatian's genitive and accusative plural are identical for every gender) — the pair innovates together, preserving that inherited pairing rather than splitting it.
5. **The clitic follows the full form, deliberately** — [[../Grammar/Personal Pronouns|Personal Pronouns]]'s page explicitly reversed an earlier draft position here: if speakers need this disambiguation in actual production, that need applies at least as much to the high-frequency clitic as to the stressed form, so [[их]] → [[ех]] moves in step with њих → њех rather than lagging behind it.

## Register

Same closed-class status as [[оне]]. Per [[../Grammar/Clitic Ordering|Clitic Ordering]], full њех is required after a preposition and for contrastive emphasis; [[ех]] takes the ordinary second-position clitic slot otherwise — following the same pattern as every other full/clitic pair in this paradigm, despite њех/[[ех]] being new material rather than inherited.
