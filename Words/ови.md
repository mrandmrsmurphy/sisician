# ови (ovi)

**Status: exploratory/tentative.** Masculine plural counterpart to [[овај]] — see [[../Grammar/Demonstrative Pronouns|Grammar/Demonstrative Pronouns]] for the full paradigm. See [[../Sisician|Sisician]] for the hub page.

## Meaning

"These" — masculine plural, genuinely-masculine referents only (old-neuter-plural reference goes to [[ове]] instead, matching [[../Words/они|они]]'s own exemption).

**Not homophonous with anything already built**, unlike its medial counterpart [[ти]] — ови is one letter (в vs. н) from [[../Words/они|они]] "they (masc.)," a near-pair worth noting for the same reason [[ова]]/[[../Words/она|она]] is, but not an actual collision.

## Etymology

**Inherited directly from Proto-Slavic \*ovi — no suffixation needed**, already a full-vowel plural nominative form (confirmed via Wiktionary's *ovъ reconstruction, which lists *\*ovi* as the masculine nominative plural directly) and matching real Serbo-Croatian *òvī* exactly.

## Register

Closed-class grammatical vocabulary, same status as every other pronoun entry.

## Related

[[овај]] (masc.sg.), [[ова]] (fem.sg.), [[ове]] (fem.pl.) — ови's own paradigm. [[ти]] — the medial counterpart, the one cell in this whole set with a genuine inherited homophone.
