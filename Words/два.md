# два (dva)

**Status: exploratory/tentative.** See [[../Grammar/Numerals|Grammar/Numerals]] for the full paradigm. See [[../Sisician|Sisician]] for the hub page.

## Meaning

"Two," masculine (and, per [[../Grammar/Nominal Morphology|Nominal Morphology]]'s neuter merger, genuinely-masculine referents only — old-neuter-plural referents use [[две]] instead, matching [[../Words/оне|оне]]'s precedent).

## Etymology

**Proto-Slavic \*dъva → два directly — no Croatian/Slovene fork at all.** Unlike [[један]], the jer here is already followed by a full vowel (-a) in the reconstruction itself, not built by suffixation, and simply drops (weak), leaving the onset cluster **dv-** — already checked as legal against [[../Phonology/Phonotactics|Phonotactics]]'s own onset-cluster inventory before this word was coined. Real Croatian and Slovene both show *dva*, unmodified — the cleanest, most-agreed-upon word in the whole 1–10 set.

## Register

Closed-class grammatical vocabulary, same status as every other numeral entry.
