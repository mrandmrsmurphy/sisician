# овом (ovom)

**Status: exploratory/tentative.** The proximal counterpart to [[том]] — see [[../Grammar/Demonstrative Pronouns|Grammar/Demonstrative Pronouns]] for the full paradigm. See [[../Sisician|Sisician]] for the hub page.

## Meaning

"With this (one)" — instrumental singular feminine of [[ова]].

## Etymology

**Proto-Slavic \*ovojǫ → овом**, the identical -ом ending family as [[том]], [[../Words/он|он]]'s њом, and [[../Grammar/Adjective Agreement|Adjective Agreement]]'s нувом. **Same unresolved *e→o vowel history already flagged on [[../Words/њом|њом]]/[[../Words/њој|њој]] and inherited by [[том]]** — not re-litigated here, the same open question one root over. Matches real Serbo-Croatian *òvōm* exactly.

## Register

Closed-class grammatical vocabulary, same status as every other pronoun entry.

## Related

[[ова]] (nominative), [[овој]] (dative), [[ову]] (accusative). [[том]] — the medial counterpart, same unresolved vowel history.
