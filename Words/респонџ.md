# респонџ (respondž)

**Status: exploratory/tentative.** The concrete noun "answer," formed directly from [[../Words/респонџати|респонџати]]'s own verb stem rather than borrowed as a separate Latin noun — see Etymology for why, and [[../Sisician|Sisician]] for the hub page.

## Meaning

"Answer, response" — the concrete noun (a specific reply), replacing native **одговор** entirely. **The sole modern word** — одговор is not built as its own `Words/` page, the same "superseded, not a separate coexisting word" treatment already given to дешет's десет, абкле's одкле, фамаља's породица/\*obitělь, and денајр's \*skotъ.

## Declension (a-declension, masculine, soft stem)

The second bisyllabic masculine a-declension noun built, after [[../Words/денајр|денајр]] — but **soft-stem, not hard**, since final **џ** is in the established soft-stem trigger set (ц дз ч џ ш ж љ њ ј, per [[../Grammar/Adjective Agreement|Adjective Agreement]]). This is the vault's first *masculine* soft-stem a-declension noun ([[../Words/сунце|сунце]] was the first soft-stem example overall, but neuter).

|---|---|---|
| Nominative | респонџ /resˈpondʒ/ | респонџеви /resˈpondʒevi/ |
| Genitive | респонџа /resˈpondʒa/ | респонџева /resˈpondʒeva/ |
| Dative | респонџу /resˈpondʒu/ | респонџевима /resˈpondʒevima/ |
| Accusative | респонџ /resˈpondʒ/ (inanimate = nom.) | респонџеве /resˈpondʒeve/ |
| Instrumental | респонџем /resˈpondʒem/ | респонџевима /resˈpondʒevima/ |

**Two real hard/soft divergences confirmed together for the first time.** [[../Grammar/Declension Classes|Declension Classes]] previously stated only that hard/soft a-declension nouns differ in the instrumental singular (-ом vs. **-ем**, confirmed here: респонџем, not †респонџом). This word adds the second, previously-unstated half of the same real Croatian pattern: the plural stem extension itself is hard/soft-conditioned too — **-ов-** for hard stems ([[../Words/денајр|денајр]]'s денајрови) vs. **-ев-** for soft stems (респонџеви, not †респонџови) — the identical o/e alternation showing up in a second cell, not a separate new rule. Real, standard Croatian morphology (*muž→muževi*, *kralj→kraljevi*, not *mužovi*/*kraljovi*), generalized here for the first time on [[../Grammar/Declension Classes|Declension Classes]].

**Stress: root-anchored**, on **-спон-** throughout (respо́ndʒ, resˈpondʒa, resˈpondʒevi, etc.) — the same syllable [[../Words/респонџати|респонџати]] stresses, since this noun *is* that verb's own root.

## Etymology

**Not a separately-borrowed Latin noun — a zero-derivation from [[../Words/респонџати|респонџати]]'s own verb stem**, matching a real, well-known native Slavic word-formation pattern rather than importing a second Latin word for the same concept. Real Croatian/Serbian **говор** ("speech"), **разговор** ("conversation"), and the very native word this entry displaces, **одговор** ("answer"), are *all* bare deverbal nouns built directly from **говорити** ("to speak") with no suffix at all — a real, productive alternative to the more familiar *-nje* deverbal-noun pattern ([[../Grammar/Verbal Categories|Verbal Categories]]'s own *-nje/-če*), reserved in real Slavic for certain basic, high-frequency action-nouns.

Sisician does the identical thing here, just with a Dalmatian-sourced verb root instead of a native one: **респонџ-** (the bare stem behind [[../Words/респонџати|респонџати]]), used directly as a masculine noun with no additional suffix — the same zero-derivation process real говор/разговор/одговор already show, applied for the first time to a borrowed root rather than a native one. This is presented as a deliberate echo of native word-formation, not a coincidence: the whole point of "Romance nouns become Slavic nouns" ([[../Phonology/Design Principles|Design Principles]]) extends naturally to "Romance-derived roots use native word-formation," and zero-derivation is exactly as native a process as suffixation with *-nje*.

## Register

Dalmatian-formal historically, but — like [[../Words/абкле|абкле]] and [[../Words/дешет|дешет]] — expected to be the plain, unmarked modern word rather than staying a felt loanword. Crosses [[../Etymology/Semantic Domains|Etymology/Semantic Domains]]'s Layer I boundary the same way [[../Words/фамаља|фамаља]] does (basic communicative vocabulary, not urban/civic Layer II), worth a brief cross-reference there rather than silence.
