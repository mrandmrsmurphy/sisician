# Etymology: Methodology

How loanwords should be recorded and how doublets should work. See [[Sisician]] for the hub page and [[Etymology/Semantic Domains]] for which domains each source language contributes to.

## Romance Loans Should Have History

A Romance loan should have a date and a pathway. For each important loan, record:

1. Dalmatian source form
2. approximate date of borrowing
3. semantic meaning at borrowing
4. Sisician adaptation
5. phonological changes
6. morphological class
7. semantic development
8. modern meaning

The ideal outcome is a real derivational chain:

> Dalmatian form → Old Sisician form → Middle Sisician form → Modern Sisician form

rather than a flat substitution ("Italian word → replace Croatian word"). The language must have **etymological archaeology** — this record template should be filled in for every word entry once [[Conlang Workflow]] Phase 2 begins, the same way the sibling `../gweddish` vault records `proto-germanic:` and similar fields on its word files (see that vault's `Word Best Practices.md` for a working precedent of this kind of per-word etymology record).

## Romance-Slavic Doublets

One desirable feature is semantic doublets, the way English has *ask/question*, *kingly/royal*, *freedom/liberty*, *begin/commence*. Sisician can have an inherited Slavic term alongside a Dalmatian-derived term for the same concept, differing in register: an ordinary/native word vs. a civic/administrative Romance word. Later the distinction can become colloquial/formal, rural/urban, old/modern, emotional/legal, native/learned — the original etymological distinction can disappear while the semantic/register distinction remains. This is a deliberate feature to design for once real vocabulary construction starts, not an accident to avoid.
